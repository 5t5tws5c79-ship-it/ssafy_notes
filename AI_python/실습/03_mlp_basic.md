## 1. 오늘의 학습 목표

- 신경망이 어떻게 생겼는지 이해하기
- 모델이 어떻게 똑똑해지는지: **순전파 → 손실 → 역전파 → 업데이트**의 4단계 이해
- 파이토치(PyTorch) 코드에서 위 4단계 중 어느 부분에 해당하는지 짚어낼 수 있기

**MLP는 옛날 기술 아닌가요?**

- MLP(Multi-Layer Perceptron)는 **모든 딥러닝의 기본 부품**
- 오늘 배우는 학습 4단계(순전파-손실-역전파-업데이트)는 CNN, 트랜스포머, LLM 파인튜닝까지 **똑같이 적용**되는 원리

### 미리 알아두는 용어 정리

| 용어 | 한 줄 정의 | 일상 비유 |
|------|-----------|-----------|
| **특징(Feature)** | 모델에게 주는 입력 정보 하나하나 | 사람을 소개할 때의 '키, 나이, 직업' |
| **회귀(Regression)** | 숫자를 맞히는 문제 | 내일 기온은 몇 도? |
| **분류(Classification)** | 종류를 맞히는 문제 | 이 사진은 개인가 고양이인가? |
| **선형(Linear)** | 직선으로 표현되는 관계 | 1개에 500원 → 10개면 5000원 |
| **비선형(Non-linear)** | 직선으로 표현 안 되는 관계 | 야근 1시간은 버티는데 5시간은 3배 더 힘듦 |
| **가중치(Weight, w)** | 각 입력을 얼마나 중요하게 볼지 | 소개팅에서 '성격 70%, 외모 30%' |
| **편향(Bias, b)** | 판단 기준선을 통째로 옮기는 값 | 내 합격 커트라인이 남보다 높다/낮다 |
| **파라미터** | 모델이 학습으로 스스로 찾는 값 (w, b) | 요리사가 경험으로 찾은 소금량 |
| **하이퍼파라미터** | 사람이 미리 정해주는 값 (층 수, 학습률) | 요리사에게 준 냄비 크기, 불 세기 |
| **XOR** | 두 입력이 서로 다를 때만 참(1) | "둘 중 하나만 골라" (둘 다는 안 됨) |

> XOR은 강사님이 특히 짚어서 설명하신 용어 — 뒤에서 XOR 문제로 다시 등장함

## 2. 딥러닝의 등장 — 고전적 머신러닝의 한계

**특징 공학(Feature Engineering)이란?**

- 사람이 직접 "이게 중요한 특징이야"라고 찾아서 알려줘야 함
- 사람이 특징을 못 찾으면, 모델은 절대 맞출 수 없음 — 이게 "특징 공학"의 한계

**딥러닝은 스스로 힌트(특징)를 찾는다**

- 사람: "픽셀 값을 줄 테니, 네가 (특징을) 찾아봐"
- 은닉층에서 "귀 모양" 같은 특징을 모델이 스스로 추출(만들어)함

**고전 머신러닝 vs 딥러닝 비교**

| 비교 항목 | 고전 머신러닝 | 딥러닝 |
|-----------|----------------|--------|
| **특징 추출** | 사람이 직접 설계 | 모델이 스스로 학습 |
| **잘 맞는 데이터** | 표(엑셀) 형태의 정형 데이터 | 이미지·음성·텍스트 등 비정형 데이터 |
| **데이터가 많아지면** | 어느 순간 성능이 정체 | 계속 상승 |
| **필요 자원** | 적음 (노트북으로 OK) | 많음 (GPU 필요) |
| **결과 설명** | 비교적 쉬움 | 어려움 (블랙박스) |

> 요약: 엑셀 같은 정형 데이터는 고전적 머신러닝이 유리하고, 이미지·음성 등은 딥러닝이 유리함
>
> **고전적 머신러닝**: 컴퓨터에게 데이터를 주고 그 안에서 규칙을 스스로 학습하게 하는 방식이지만, **특징은 사람이 가공해서 알려줘야** 했음
> **딥러닝**: 인공신경망 기반의 딥러닝이 등장하면서, **특징 추출까지 모델이 직접** 함

## 3. 퍼셉트론(Perceptron)의 탄생

- **P(퍼셉트론)** — 프랑크 로젠블랫(Frank Rosenblatt)이 던진 질문: **"기계도 스스로 학습할 수 있을까?"**
- 아이디어: **뇌 신경세포(뉴런)를 흉내내보자**
- 여러 정보를 저울에 달아서, 그 합이 **기준선을 넘으면 1, 못 넘으면 0**을 출력하는 장치가 바로 **퍼셉트론**
- 데이터 사이에 **하나의 직선**을 그어서 두 그룹을 나누는 것과 같음
- **선형 분리(linear separation)가 가능한 문제**들을, 기계가 스스로 규칙을 찾을 수 있다는 가능성을 처음으로 보여줌

**퍼셉트론의 부품**

| 부품 | 역할 |
|------|------|
| **입력 x** | 모델에 들어오는 값 |
| **가중치 w** | 각 입력의 중요도 |
| **가중합** | 입력×가중치를 모두 더한 값 |
| **활성화 함수** | 가중합을 보고 "신호를 켤지 말지(활성화시켜 전달할지)" 결정하는 스위치 |

- 퍼셉트론이 하는 일: **데이터 사이에 하나의 직선을 그어서 두 그룹을 나누는 것**과 같음
- **선형 분리가 가능한 문제**를 잘 품 (예: 스팸 메일 분류, 암 진단처럼 두 그룹으로 나뉘는 문제)
- 기계가 데이터를 보고 스스로 경계선(decision boundary)을 찾아낼 수 있다는 가능성을 보여준 알고리즘

**기하학적으로 이해하기**

- 가중합 = 우리가 아는 **직선의 방정식**과 같음
- 퍼셉트론의 판단 기준선은 **z = 0**인 지점
- **가중치를 바꾼다** = 직선의 **기울기**가 바뀐다
- **편향을 바꾼다** = 직선이 **위아래로 평행이동**한다
- **학습한다** = 데이터를 가장 잘 나누는 **기울기와 위치**를 찾아가는 것

## 4. 퍼셉트론이 벽에 부딪히다 — XOR 문제와 AI의 겨울

### XOR 문제

- **XOR 문제**를 하나의 직선으로는 도저히 해결할 수 없었음
- 예시: "가격이 싸고 맛있다", "비싸고 맛없다"는 판단하기 쉽지만, **"싸고 맛없는 집"과 "비싸고 맛있는 집"**처럼 대각선끼리 같은 그룹인 경우는, 직선 하나로 나눌 수가 없었음

### AI의 겨울 (AI Winter)

- XOR 문제는 **층을 여러 개 쌓으면(다층 구조) 풀린다**는 것은 알았음
- 하지만, 층을 여러 개 쌓았을 때 **각 층의 가중치를 어떻게 학습시켜야 하는지**에 대한 답이 없었음 — 이것이 문제였음
- **역전파(Backpropagation) 알고리즘이 1986년에 대중화**되면서 이 문제가 해결됨 → 신경망 연구의 새로운 시작이 됨

## 5. MLP (Multi-Layer Perceptron, 다층 퍼셉트론)

- 퍼셉트론을 **여러 층으로 쌓아 만든, 딥러닝의 가장 기본적인 모델**

| 층 | 역할 |
|------|------|
| **입력층** | 데이터가 처음 들어오는 곳 (예: 8×8 이미지) |
| **은닉층** | 입력층과 출력층 사이에 1개 이상 존재. 데이터의 핵심 특징을 추출하고 학습하는 가장 중요한 부분. **층이 깊어질수록 더 복잡한 패턴을 학습**할 수 있음 |
| **출력층** | 최종 예측 결과를 내보내는 곳 (예: 0~9 중 하나로 분류) |

**MLP의 한계 — 이미지에 약한 이유**

- 8×8 이미지를 **플래튼(flatten, 평탄화)**해서 64개의 값을 한 줄로 늘어놓아야 함
- 이 과정에서 **픽셀의 위치 정보가 사라짐**
- 그래서 MLP는 이미지 처리에 상대적으로 약함 (→ 이후 CNN 등장의 배경)

### 왜 XOR이 층을 쌓으면 풀릴까?

- 직선을 **여러 개** 사용하기 때문
- **은닉층은 "종이를 접는 손"**과 같음 — 데이터가 놓인 공간 자체를 구겨서(접어서) 다시 배치함
- 은닉층이 하는 일: **직선으로 나눌 수 있도록, 공간 자체를 바꿔놓는 것**
- 층이 깊어질수록 → 공간을 더 여러 번 접음 → 더 복잡한 모양(경계)도 나눌 수 있게 됨

## 6. 활성화 함수와 기울기 소실

### 활성화 함수 (Activation Function)

- 비유: **신호를 켜고 끄는 스위치**
- **역할**: 활성화 함수가 없다면, 신경망을 아무리 깊게 쌓아도 결국 **하나의 긴 선형 함수**와 똑같아짐
- 활성화 함수는 여기에 **비선형성(non-linearity)**을 추가해서, 복잡한 패턴을 학습할 수 있게 해주는 스위치 역할을 함

**시그모이드 → ReLU로 넘어간 이유**

- 과거에는 **시그모이드(Sigmoid)**를 사용했는데, 역전파 시 오차 신호가 입력층에 가까운 앞쪽으로 전달될수록 **점점 사라지는(기울기 소실, Vanishing Gradient)** 문제를 일으켰음
- 요즘은 **ReLU**를 주로 사용: 입력이 0보다 크면 값을 그대로, 0보다 작으면 0을 출력 → **기울기 소실 문제를 해결**하고, **계산 속도도 매우 빠름**

### 기울기 소실이 왜 일어나는가?

- 시그모이드 함수는 **최대 기울기가 0.25**인 S자 곡선
- 퍼셉트론의 층을 10번 거치면, 기울기가 곱해지면서 **0.25¹⁰**가 됨 → **거의 0에 수렴**
- 퍼셉트론이 가중합을 구해 "가중치를 이렇게 고쳐라"라고 다음(이전) 층에 신호를 보내는 것인데, 이 신호가 앞쪽 층까지 도달하지 못하고 사라져 버리는 것

> `[개인 메모 · 시험범위 아님]` 개인적 궁금증: ReLU 함수는 미분하면 불연속인데(z=0 지점에서 기울기가 0→1로 갑자기 바뀜), 왜 사용하는 걸까? 불연속점이 있는 함수는 안 좋은 것 아닌가? 두 번 미분할 일이 없으니 괜찮은 건가?
>
> **답변**: 좋은 직관이다 — 실제로 핵심 이유 중 하나가 바로 그것이다.
>
> 먼저 정확히 짚자면, **ReLU 함수 자체는 연속(continuous)**이다 (z=0에서 값이 뚝 끊기지 않고 매끄럽게 0으로 이어짐). 다만 그 **도함수(1차 미분)가 z=0에서 불연속**(0에서 1로 순간적으로 점프)이고, 엄밀히는 z=0인 정확히 그 점에서는 미분이 정의되지 않는다(뾰족한 꺾인 점, kink).
>
> 그런데도 실전에서 문제가 되지 않는 이유는 세 가지다.
> 1. **불연속점이 딱 한 점(z=0)뿐이다.** 실수 전체 범위 중 정확히 z=0을 맞힐 확률은 사실상 0에 가깝고(부동소수점 계산에서는 더더욱), 설령 걸리더라도 그 지점에서는 그냥 관례적으로 미분값을 0이나 1로 정해서(이를 "서브그래디언트, subgradient"라고 함) 계산을 계속 진행하면 그만이다.
> 2. **경사하강법·역전파는 1차 미분(기울기)만 있으면 충분하다.** 뉴턴법처럼 2차 미분(곡률, Hessian)까지 쓰는 고급 최적화 기법이 아니라면, "미분 가능한 곡선이 매끄러운가"는 크게 중요하지 않다. 정확히 짐작한 대로, **"두 번 미분할 일이 없으니 괜찮다"는 직관이 맞다** — 다만 그보다 더 근본적인 이유는 3번이다.
> 3. **오히려 이 "불연속"이 장점으로 작용한다.** ReLU의 기울기는 z>0에서 정확히 **1**, z<0에서 정확히 **0**이다. 시그모이드처럼 기울기가 항상 1보다 작은 값(최대 0.25)으로 매끄럽게 변하는 함수는, 여러 층을 거치며 그 작은 값들이 계속 곱해져서 기울기가 기하급수적으로 작아지는(기울기 소실) 문제가 생긴다. 반면 ReLU는 값이 살아있는 구간(z>0)에서는 기울기가 항상 정확히 1이라서, 아무리 곱해도 값이 줄어들지 않는다 — 이게 바로 ReLU를 쓰는 핵심 이유다.
>
> 즉 "매끄럽지 않다(불연속)"는 성질 자체는 사소한 대가일 뿐이고, 그 대신 얻는 "기울기가 죽지 않는다"는 이득이 훨씬 크기 때문에 ReLU가 표준으로 자리잡은 것이다.

**ReLU가 요즘도 표준인가?**

- ReLU는 규칙이 매우 단순: 0보다 크면 값을 그대로, 0보다 작으면 0
- 기울기는 1 아니면 0 → 신호가 사라지지 않고, 계산도 빠르며, 1은 아무리 곱해도 1이라서 안정적
- 다만 최신 모델들은 GELU 등 ReLU의 변형/개선된 활성화 함수를 사용하는 경우도 많음

## 7. 모델은 어떻게 학습하는가? — 학습 4단계

**요리 비유로 이해하기**

| 단계 | 요리 비유 | 실제 의미 |
|------|-----------|-----------|
| **1. 순전파(Forward)** | 일단 요리해본다 | 입력 → 예측값 계산 |
| **2. 손실 계산(Loss)** | 먹어보고 평가한다 | 예측 vs 정답, 얼마나 틀렸는지 계산 |
| **3. 역전파(Backpropagation)** | 원인 분석 (짠 게 소금 탓인지 간장 탓인지) | 누구(어느 가중치) 책임인지 거꾸로 추적 |
| **4. 옵티마이저(Optimizer)** | 재료 조절 (물 붓기) | 실제로 w, b 값을 조금씩 수정 |

- 이 한 바퀴(1~4단계)를 **수천 번 반복**하는 것이 바로 **트레이닝(학습, Training)**

### 1단계: 순전파(Forward Propagation)

- 입력 → 은닉층을 거쳐 → 출력층까지, 최종 예측값을 계산하는 과정
- 초기에는 가중치가 무작위이므로, 매우 엉터리인 예측 결과가 나옴
- 비유: 랜덤한 레시피대로 일단 한 번 만들어본다 — 첫 시도는 당연히 맛없다

**왜 가중치를 (0이 아니라) 랜덤으로 초기화할까?**

- 강사님 설명: 모든 가중치를 똑같은 값(0)으로 초기화하면, 모든 뉴런이 똑같은 특징을 배우게 되어 다양성이 떨어짐

> 이 설명에 대해 "이래도 괜찮은 것 같은데?"라는 의문이 들어 검증을 요청함 (아래는 그에 대한 답변)
>
> **답변 (대칭성 붕괴, Symmetry Breaking)**: 강사님의 설명이 정확하다. 조금 더 구체적으로 풀어보면:
>
> 만약 어떤 층의 모든 뉴런이 **완전히 똑같은 가중치**(예: 전부 0)로 시작한다면, 그 층의 모든 뉴런은 **항상 똑같은 입력을 받고, 항상 똑같은 계산을 해서, 항상 똑같은 출력**을 낸다. 그리고 결정적으로, 역전파를 할 때도 이 뉴런들은 **항상 똑같은 기울기(gradient)**를 전달받는다. 즉, 모든 뉴런이 매 스텝마다 정확히 똑같이 업데이트되기 때문에, 아무리 오래 학습시켜도 그 뉴런들은 **영원히 서로 완전히 똑같은 상태**로 남는다.
>
> 이렇게 되면, 예를 들어 은닉층에 뉴런이 100개 있어도, 사실상 뉴런 1개짜리 층을 100번 복사해놓은 것과 다를 바가 없어진다 — 즉 100개 분량의 표현력(capacity)을 완전히 낭비하게 되는 것이다.
>
> **랜덤 초기화**는 이 문제를 처음부터 막아준다. 각 뉴런이 서로 다른 초깃값에서 출발하면, 첫 순전파부터 뉴런마다 조금씩 다른 계산을 하게 되고, 그러면 역전파 때도 서로 다른 기울기를 받게 되어, 학습이 진행되면서 뉴런들이 각자 다른(서로 보완적인) 특징을 배우도록 갈라져 나갈 수 있다.
>
> (참고로 핵심은 "0이라서" 문제가 아니라 "모두 같은 값이라서" 문제라는 점이다 — 예를 들어 편향(bias)은 보통 0으로 초기화해도 괜찮은데, 그건 가중치가 이미 랜덤하게 갈라져 있어서 대칭이 깨진 상태이기 때문이다.)

### 2단계: 손실함수(Loss Function)

- 순전파로 나온 엉터리 예측 결과와 실제 정답을 비교해서, 얼마나 틀렸는지를 **하나의 숫자**로 계산

| 문제 유형 | 손실함수 |
|-----------|-----------|
| 회귀 | MSE (평균제곱오차) |
| 분류 | 교차 엔트로피 |

> 손실함수(성적표)에는 철학이 있다 — 교차 엔트로피는 "확신에 차서 틀리는 것"에 큰 벌점을 주고, "모르면 모른다고 솔직하게 답하는 것"에는 상대적으로 관대함

- 손실값을 **최소화**하는 것이 학습의 목적

### 3단계: 역전파(Backpropagation)

- 손실이 예를 들어 5.3이 나왔다고 할 때, 이 오차를 크게 만든 **책임을 출력층에서부터 거꾸로 전달**해가면서 계산
- 각 가중치는 **자신의 책임량에 비례**해서, 손실을 줄이는 방향으로 조금씩 업데이트됨
- 비유: 요리가 "너무 짜고 덜 달다"는 문제의 원인을 분석해서, 각 가중치를 얼마나 어느 방향으로 조절해야 하는지에 대한 **수정 지침서**를 계산하는 과정

### 4단계: 옵티마이저(Optimizer)

- 역전파로 계산된 책임(기울기)을 바탕으로, 손실함수 값이 최소가 되는 **최적의 가중치를 효율적으로 찾아가는 알고리즘**
- 역전파를 통해 계산된 모든 가중치의 기울기와, 학습률을 사용하여 손실이 줄어드는 방향으로 실제 가중치 값을 업데이트

**Adam 옵티마이저**

- 요즘은 Adam의 변형(AdamW 등)도 많이 쓰지만, **Adam은 그 이전 세대의 표준 옵티마이저**
- **관성(momentum)**을 이용해 학습 방향을 유지
- 각 가중치마다 **학습률을 적응적으로 조절**하여, 빠르고 안정적으로 최적의 가중치를 찾아냄

## 8. [심화] 역전파 진행 과정 — "책임 신호"

> `[개인 메모 · 시험범위 아님]` 심화 참고 자료 — 정리만 해두는 용도

역전파를 **"책임 신호"**라는 개념으로 조금 더 구체적으로 풀어낸 설명.

**용어**
- **책임 신호** = 뉴런의 기울기 = 영향력 — 뉴런의 출력 값이 최종 오차(L)에 얼마나 영향을 미쳤는지
- **최종 책임 신호** = 가중치의 기울기 — 그 뉴런으로 들어온 각 가중치가 최종 오차에 얼마나 영향을 미쳤는지 (실제 가중치 업데이트에 사용되는 값)

### 역전파 진행 과정 (1/2)

1. 예측값과 정답의 차이에서 하나의 **"최종 오차(L)"**가 발생
2. "최종 오차(L)"가 뒤로 전파되면서, 각 뉴런은 최종 오차(L)에 대한 각기 다른 **'책임 신호'**를 전달받음
   - 책임 신호는 **뉴런의 출력 값이 최종 오차(L)에 얼마나 영향을 미쳤는지**를 나타냄
   - 수학적으로는 "최종 오차(L)"를 "각 뉴런의 출력"으로 **편미분**한 것
3. 뉴런 내부의 각 (가중치(w) × 입력데이터(x))는 책임 신호에 각기 다른 영향을 미쳤고, 이 영향력에 맞춰서 가중치를 수정해야 함
   - 영향력이 크면, 가중치 수정도 더 많이 해야 함

### 역전파 진행 과정 (2/2)

4. (가중치(w) × 입력데이터(x))의 영향력에서, 실질적으로 책임 신호에 영향을 주는 부분은 **"입력데이터(x)"**다.
   - 우리가 궁금한 것은 "가중치를 조절했을 때 결과가 얼마나 변할까?"이고, 이 **가중치의 영향력을 결정하는 것은 '입력 데이터'에 비례**하여 결정됨
   - 예를 들어 방정식 `b = 7 * a` 가 있을 때, a의 영향력을 보고 싶으면 결국 a를 고정하고 7을 쳐다봐야 함
   - 그리고 이것이 바로 미분(편미분)이다!
5. 이 계산 단계에서는 기존에 있던 가중치(w)는 신경 쓰지 말고, 입력데이터(x)와 책임 신호를 곱해서 **최종 책임 신호(가중치의 기울기)**를 계산한 후, 학습률과 곱해서 각 가중치 값을 업데이트함
   - 입력 데이터가 커지면 → 영향력도 커지고 → 가중치의 업데이트 변화량도 커져야 하고 → 학습률과 곱해질 최종 책임 신호 값도 커져야 함
