## 2. 회귀란 무엇인가

**회귀(Regression)** — 도대체 뭐가 어디로 돌아간다는 걸까?

- 유래: 아버지 키가 아무리 커도, 아들 키는 전체 평균 쪽으로 돌아가려는 경향성이 발견됨 → 이 현상에 붙은 이름이 **평균으로의 회귀**
- 이 수업에서의 의미: 데이터는 아무리 흩어져 있어도 결국 **하나의 선**으로 돌아간다 → 흩어진 점들 뒤에 숨은, 돌아갈 선을 찾는 것이 회귀

> **흩어진 점 → 숨어있는 선 찾기**

### 가중치(Weight)와 편향(Bias) 비유

- **편향(Bias)**: 택시 기본요금
- **가중치(Weight)**: 킬로(km)당 요금

## 3. AI 만드는 법 — 규칙 기반 vs 학습 기반

| 방식 | 설명 | 한계/특징 |
|------|------|-----------|
| **규칙 기반** | 사람이 일일이 "이럴 땐 이렇게 해"라고 규칙을 정해줌 | 세상의 모든 규칙을 만들 수 없고, 예외 대처가 어려움 |
| **학습 기반** | 컴퓨터에게 데이터를 주고, 데이터 안에서 규칙을 스스로 배우게 함 | **현대 AI의 핵심** |

## 4. 머신러닝 개념 리캡

**머신러닝**: "데이터에서 패턴(관계)을 찾는 것"

**예시 — '공부 시간-성적'**: 최적의 예측선(Best-fit line)을 찾는 개념

| 구성 요소 | 설명 |
|-----------|------|
| **산점도 (파란색 점)** | 각각의 점은 수집된 데이터 하나하나(공부 시간, 실제 성적)를 좌표 평면에 표시한 것 |
| **최적선 (빨간색 선)** | 흩어져 있는 데이터 점들의 전반적인 경향을 가장 잘 나타내는 하나의 예측 직선. 이 직선이 바로 우리가 찾으려는 **모델(Model)** |
| **오차 (회색 점선)** | 각 데이터의 실제 성적(파란 점)과 우리가 예측한 직선 위의 성적(빨간 선) 사이의 거리. 이 오차들의 총합이 작을수록 더 좋은 모델 |
| **방정식 (y = wx + b)** | 빨간색 예측선을 수학적으로 표현한 것 |

- 방정식에서 **w = Weight(가중치/기울기)**, **b = Bias(편향/y절편)**
- 머신러닝의 목표: 수많은 데이터 (x, y)를 보고, **전체 오차를 가장 작게 만드는 최적의 w(가중치/기울기)와 b(편향/y절편)를 찾아내는 것**

## 5. 머신러닝 학습 종류

| 종류 | 설명 |
|------|------|
| **지도학습** | 정답을 주고 학습 |
| **비지도학습** | 정답이 없는, 숨겨진 규칙을 찾는 학습 |
| **강화학습** | 상벌(reward/penalty)을 통해 최적의 행동 방식을 학습하는 방법 (예: 알파고). 로봇 제어, 자율주행, 게임 AI 등에 활용 |

## 6. 지도학습 유형 — 회귀 vs 분류

- 정답이 **연속적인 숫자**면 → **회귀(Regression)** — 여기서 **선형회귀**를 배움
- 정답이 **카테고리(범주)**면 → **분류(Classification)** — 여기서 **로지스틱 회귀**를 배울 예정

## 7. 선형 회귀 (Linear Regression)

- 수많은 데이터를 **하나의 직선**으로 표현하겠다는, 가장 간단하고 직관적인 방법
- 특성(feature)이 하나일 때는 직선, 다차원(특성이 여러 개)인 경우에는 **평면/초평면(hyperplane)**

| 구분 | 설명 | 예시 |
|------|------|------|
| **단순 선형 회귀** | 하나의 특성만 있을 때 | — |
| **다중 선형 회귀** | 여러 특성이 있을 때 | 캐럿, 투명도, 깊이를 모두 고려한 다이아몬드 가격 예측 |

### 모델 = 가설 (Hypothesis)

- 이 직선(예측 직선)을 **모델(Model)** 또는 **가설(Hypothesis)**이라고 부름
- **왜 "가설"이라고 부르나?** 아직 검증해보지 않았고, 우리가 세운 하나의 주장이기 때문

### 어떤 모델이 좋은 모델일까?

- **실제 데이터들과의 거리가 가장 작은 직선**이 좋은 모델
- 이 "좋음의 정도"를 숫자로 나타낸 것이 **비용함수(모델의 성적표)**

> 곡선으로 예측선을 그리는 방법은 **다항회귀**라고 부르는데, 곡선은 모델이 데이터를 그대로 외워버리는 **과적합** 가능성이 있음

---

## 8. 좋은 모델이란? — 비용함수 (Cost Function)

**비용함수 = 모델의 최종 시험 성적표**

- 모델이 데이터를 평균적으로 얼마나 잘 예측하는지 나타내는 하나의 점수
- **벌점**으로 생각하면 됨 — 낮을수록 좋은 모델
- 각 문제에서 틀린 부분(손실)들이 모여 최종 성적(비용)이 결정됨

**비용함수가 하는 일**
1. 모델 평가
2. 학습 방향 제시

### 비용(Cost) vs 손실(Loss) — 헷갈리지 말 것

| 용어 | 의미 |
|------|------|
| **비용함수 (Cost Function)** | 전체 데이터에 대한 최종 성적표 |
| **손실 (Loss)** | 데이터 하나에 대한 단일 오차 |

> 엄밀하게는 다른 개념: **비용함수 = 손실(loss)의 합 / 데이터 개수**
>
> 그런데 왜 종종 혼용해서 쓰나? 개별 데이터의 손실을 줄이는 과정을 통해 결국 전체 비용을 줄인다는 의미를 내포하고 있기 때문.

## 9. 비용함수 구하는 법 — MSE vs MAE

회귀에서 주로 쓰는 비용함수: **평균제곱오차(MSE, Mean Squared Error)**

- 오차를 제곱해서 평균을 낸 값
- **왜 제곱?** 오차가 음수일 수도 있기 때문에, 부호를 없애고 절대적인 크기(절대량)를 더하고 싶어서
- (참고: 절댓값의 평균을 쓰면 **MAE, Mean Absolute Error**)

### MSE 계산 절차

1. 각 데이터의 실제값과 예측값의 차이(오차)를 구한다
2. 각 오차를 모두 **제곱**하여 양수로 만든다 → 양·음수가 상쇄되지 않고, 큰 오차에는 더 큰 패널티가 부여됨
3. 제곱의 총합을 데이터 개수로 나누어 **평균**을 구한다

**예시**: 공부 시간과 점수의 상관관계로 시험 성적을 예측하는 모델

> MSE를 0에 가깝게 만드는 최적의 모델(w, b)을 찾는 것 → **최소제곱법(Least Squares Method)**

## 10. 최적 파라미터 찾기 — 정규방정식 vs 경사하강법

w와 b를 어떻게 찾을까?

1. **정규방정식(Normal Equation)** — 해석적 방법
2. **더듬어가며 찾기** — **경사하강법(Gradient Descent)**

### 정규방정식(최소제곱법) — 해석적 해법

- 복잡한 미분방정식을 풀어서 **한 번에** 정답을 계산
- 만들어진 수학 공식에 입력 데이터 행렬과 레이블 벡터를 대입하면, 최적의 w, b가 바로 계산되어 나옴

**정규방정식의 치명적인 단점**
- 피처가 많아지면 **역행렬 계산** 때문에 속도가 매우 느려짐 — O(n³)
- 역행렬이 존재하지 않는 데이터도 있음 → 이 경우 **SVD**로 해결 (역행렬이 없는 행렬을, 역행렬이 있는 가장 유사한 행렬로 근사해서 만들어내는 방법 — 깊은 내용이므로 참고만)
- 파라미터가 매우 많은 딥러닝에서는 사용이 사실상 불가능

> 그래서 대부분의 모델은 **경사하강법**을 채택한다.

### 정규방정식 vs 경사하강법 비교

| 구분 | 정규 방정식 | 경사 하강법 |
|------|-------------|-------------|
| **해법** | 해석적 해법 (수학 공식으로 한 번에 정답 계산) | 반복적 해법 (점진적으로 최적의 해를 찾아감) |
| **속도** | 특성(Feature) 개수가 적을 때(약 10,000개 미만) 매우 빠름 | 특성 개수가 많아도 효율적으로 동작 |
| **단점** | 특성 개수가 많아지면 역행렬 계산(O(n³)) 때문에 매우 느려짐 | 학습률(Learning Rate)을 직접 설정해야 하며, 값에 따라 성능이 크게 좌우됨 |
| **메모리** | 전체 데이터를 메모리에 로드해야 함 | 미니배치를 사용하여 대용량 데이터도 학습 가능 |
| **확장성** | 선형 회귀 등 일부 모델에만 적용 가능 | 선형 회귀를 넘어 딥러닝 등 대부분의 머신러닝 모델에 사용되는 범용적인 방법 |

> **현대 AI(딥러닝·LLM)의 99%는 경사하강법 계열로 학습한다.** LLM 파인튜닝에서 만나는 learning rate, epoch, batch size가 전부 여기서 나온 개념.

## 11. 경사하강법 (Gradient Descent)

**비유로 이해하기 — 안개 낀 산에서 계곡 바닥 찾기**

방법은 하나뿐: **경사를 느끼고 → 내리막으로 한 걸음 → 반복** (발바닥이 평평해질 때까지 = 기울기 0)

| 안개 낀 산 | 경사 하강법 |
|------------|-------------|
| 산의 지형 | 비용 함수 그래프 (MSE 밥그릇) |
| 지금 서 있는 위치 | 현재의 파라미터 w, b |
| 고도 (높이) | 비용 (벌점) — 낮을수록 좋음 |
| 발바닥으로 느끼는 경사 | 미분으로 구한 기울기(gradient) |
| 한 걸음의 보폭 | 학습률(Learning Rate) |
| 한 걸음 | 이터레이션(iteration) |
| 산 전체를 한 바퀴 | 에포크(Epoch) |
| 가짜 웅덩이 | 지역 최솟값(Local Minimum) |
| 진짜 계곡 바닥 | 전역 최솟값(Global Minimum) |

**핵심 원리**
- 최적의 파라미터를 점진적으로 찾아나가는 방법
- 비용함수의 **기울기가 0이 되는 지점**이 가장 비용이 낮은 지점
- 랜덤한 위치에서 시작 → 미분해서 현재 지점의 기울기를 구함 → 기울기 반대 방향으로 움직임 (이때 보폭이 학습률)
- 다시 현재 위치에서 경사를 확인하고, 학습률만큼 이동 → 이 과정을 반복하며 가장 낮은 지점에 도달

## 12. 경사하강법 세부 개념

### 학습률 (Learning Rate)

- 보폭이 **너무 크면** 반대편으로 튀어 올라갈 수 있음 → **발산**할 위험
- 학습률이 **너무 작으면** 수렴하는 데 너무 오래 걸림
- 실무에서도 학습률은 아주 예민하게 튜닝하는 값

### 로컬 미니멈(Local Minimum) 문제

- 시작 위치가 랜덤이기 때문에, 지역 최솟값(local minimum)에 빠질 수 있음 — 전역 최솟값이 아닌 곳에서 멈춰버릴 위험

### 이터레이션 vs 에포크

| 용어 | 정의 |
|------|------|
| **이터레이션 (Iteration)** | 데이터의 일부 또는 전체를 보고, 현재 위치의 경사를 계산해 한 걸음 이동하는 과정 |
| **에포크 (Epoch)** | 전체 데이터를 모두 한 번 훑어보면 1 에포크 |

### 배치 크기 (Batch Size)

- 기울기를 구할 때, 전체 데이터 오차의 기울기를 한 번에 구하지 않음 (너무 느리기 때문)
- 데이터를 작은 묶음(배치)으로 나눠서 처리
- 전체 데이터의 오차 기울기를 한 번에 구하는 경우에는 **1 이터레이션 = 1 에포크**

### 허용 오차 / 조기 종료 (Early Stopping)

- 모델의 오차 감소량이 매우 작아지면, 더 학습해도 성능 향상이 없다고 판단해 학습을 멈추는 조건

### 기울기 누적 스텝 (Gradient Accumulation)

- 실질적인 배치 크기를 늘리는 고급 기법
- 매 배치마다 파라미터를 업데이트하는 게 아니라, N번의 배치 간격으로 기울기를 누적한 뒤 이를 기반으로 한 번에 이동

## 13. 경사하강법의 종류

| 종류 | 설명 | 특징 |
|------|------|------|
| **배치 경사하강법 (Batch GD)** | 전체 데이터를 한 번 훑어보고 기울기를 계산. 1 에포크 = 1 이터레이션 | 정확하지만 데이터가 크면 매우 느림 |
| **확률적 경사하강법 (SGD)** | 하나의 데이터만 보고 바로 기울기를 계산 | 빠르지만 불안정함 |
| **미니배치 경사하강법 (Mini-batch GD)** | 실무에서는 절충해서, 적당한 수의 배치를 보고 기울기를 계산 | 속도와 안정성을 모두 잡음 |

> `[개인 메모 · 시험범위 아님]` 배치 수는 정해진 답이 없으며 실험적으로 구해야 함 — 사용할 그래픽카드(GPU)의 VRAM과 데이터의 크기를 고려해서 결정.

## 14. 미분과 기울기

"미분으로 기울기를 구한다"는 것이 무슨 의미인가?

**비유: 자동차 계기판의 속도계**

1. **1단계 — 평균 변화율 (우리가 이미 아는 개념)**
   - 서울에서 부산까지 400km를 4시간 만에 갔다면, 시속 100km가 평균 속도
   - 하지만 이건 전체 구간의 평균일 뿐, **지금 이 순간**의 속도는 알려주지 않음

2. **2단계 — 순간 변화율 = 미분 (우리가 알고 싶은 것)**
   - 자동차 계기판을 보면 지금 이 순간의 속도가 나옴
   - 지금 이 지점에서 얼마나 빠르게 변하고 있는가를 알려주는 것이 미분

3. **3단계 — 그래서 경사하강법에 왜 미분이 필요한가?**
   - 기울기가 크다면, 현재 위치가 (기울기) 0에서 멀다는 뜻
   - 안개 낀 산에서 우리가 알고 싶은 건 **산 전체의 경사가 아니라, 지금 내 위치의 경사** — 그걸 알아야 어느 쪽으로 얼마나 발을 내딛을지 정할 수 있음
   - **발밑의 경사를 계산해주는 도구가 미분**

> 미분 공식을 직접 유도하지는 않는다 — 라이브러리가 다 계산해주기 때문. 코드로는 `grad_a = np.mean(error * X)` 같은 형태로 구현.

**용어 정리**

| 용어 | 의미 |
|------|------|
| **모델의 기울기** | 예측 직선(y = wx + b)의 기울기 w(웨이트) — 우리가 찾아내야 할 값 |
| **미분으로 구한 기울기** | MSE(비용함수)의 기울기(grad_a, grad_b) — w와 b를 어느 방향으로 고칠지 알려주는 나침반 |

> 미분값을 보고 모델의 기울기(w, b)를 고쳐나가는 것이 바로 경사하강법.

## 15. 로지스틱 회귀 (Logistic Regression)

**선을 넘어 확률로.** 분류 문제에서 가장 기본적이면서 강력한 도구 — 피처가 어떤 그룹에 속하는지 예측하는 문제 (예: 메일 내용을 보고 스팸인지 아닌지)

### 분류 문제에서 선형회귀의 한계

- 선형회귀는 끊임없이 이어지는 직선이며, 입력값에 비례하는 값을 예측함
- 예: "암에 걸릴 확률이 150%, −30%" 같이 **해석할 수 없는 예측값**을 만들어낼 수 있음
- 넘치는 값을 트림(clip)하면 안 되나? → 안 됨. 임시방편일 뿐임

**이상치에 너무 민감함**
- 선형회귀는 모든 데이터와의 평균적인 거리를 최소화하는 것이 목적
- 이상치가 추가되면, 이상치에 따라 직선의 기울기가 바뀜 → 분류 기준선 자체가 이상치에 딸려 올라갈 수도 있음
- 회귀는 예측 하나가 크게 틀리는 정도지만, 분류(classification)는 **전체 기준 자체가 틀어질 수 있음**

**다중 분류에서 잘못된 관계를 학습**
- 분류할 그룹이 3개 이상일 경우, 그룹들 간에 (실제로는 없는) 수학적 관계가 있다고 착각할 수 있음
- 예: 개/고양이/새를 분류할 때, "개와 새의 중간이 고양이"라는 식의 실제로 존재하지 않는 수학적 관계를 학습해버릴 위험

### 시그모이드 함수 (Sigmoid)

- 선형회귀의 예측 결과(범위 무제한)를 **0~1 사이의 확률값**으로 압축
- **로지스틱 회귀**: 선형회귀의 출력을 시그모이드에 통과시켜서 확률을 예측하는 확률 예측 분류 모델

**흐름**: 입력 x → 선형회귀 → 실수 y(범위 무제한) → 시그모이드 통과 → 0~1 사이의 확률값 → (0.5 넘으면 스팸, 아니면 정상) → 분류 완성

> **한계**: 역전파에서 기울기를 전달하는 과정에서 기울기가 사라지는 **배니싱 그래디언트(Vanishing Gradient)** 문제가 발생할 수 있음. 이를 보완하기 위해 ReLU 함수 등 다른 활성화 함수들이 다양하게 사용됨.

### 왜 MSE 대신 교차 엔트로피를 쓰는가

- 로지스틱 회귀(선형 + 시그모이드)에 MSE를 그대로 사용하면, 매끈한 그래프가 아니라 **울퉁불퉁한 모양**이 되어 수많은 지역 최솟값(local minima)을 만들어냄
- 정답이 1인데 예측이 0.01이면 아주 큰 실수인데도, 기울기 소실 문제가 발생할 수 있음
- **분류 문제의 손실 함수는 교차 엔트로피!**
  - 핵심 아이디어: **틀렸을 때 얼마나 강하게 확신하면서 틀렸는가**를 반영
  - 정답이 1일 때 0.9로 예측 → 패널티가 매우 낮음
  - 정답이 1일 때 0.1로 예측 → 비용이 매우 높음
  - 정답을 더 높은 확률로 맞추도록 효과적으로 유도함

### 로지스틱 회귀 완성

**로지스틱 회귀 = 선형회귀 + 시그모이드 + 이진 교차 엔트로피**

- 경사하강법을 사용해서, **이진 교차 엔트로피 비용을 최소화**하는 방향으로 w와 b를 계속 업데이트
- 부품(비용함수)만 바뀐 것이고, 학습 원리(경사하강법)는 선형회귀와 동일

## 16. 다중 분류 — 소프트맥스 (Softmax)

**다중 분류 문제는?** → 시그모이드 대신 **소프트맥스**를 사용

- 시그모이드는 **이진(binary) 전용**
- 소프트맥스: 모델이 각 선택지에 대해 매긴 점수들을, **총합이 1이 되는 확률 분포**로 변환해주는 함수

**예시**

| 클래스 | 원점수 | 소프트맥스 통과 후 확률 |
|--------|--------|--------------------------|
| 개 | 2 | 0.7 |
| 고양이 | 1 | 0.2 |
| 새 | 0.1 | 0.1 |

→ 총합이 1이 되므로, 모델이 "개"일 확률을 70%로 가장 높게 예측했다는 것을 명확히 알 수 있음

### 시그모이드 vs 소프트맥스 비교

| 구분 | 시그모이드 (Sigmoid) | 소프트맥스 (Softmax) |
|------|------------------------|------------------------|
| **질문** | "이 사진은 고양이인가?" (Yes/No) | "이 사진은 개, 고양이, 새 중 무엇인가?" (하나 선택) |
| **출력** | 각 항목에 대한 독립적인 확률 (0~1) | 모든 항목의 확률 총합이 1이 되는 분포 |
| **주 사용처** | 이진 분류 (Binary Classification) | 다중 클래스 분류 (Multi-class Classification) |

### LLM과의 연결

- LLM은 수만 개의 후보 단어에 점수를 매기고, **소프트맥스**로 확률 분포를 만들어 다음 단어를 선택함
- **temperature**를 낮추면 → 1등 단어에 확률이 집중됨 (더 결정적인 답변)
- **temperature**를 높이면 → 분포가 평평해짐 (더 창의적인/다양한 답변)

> 오늘 배운 소프트맥스가 LLM 출력의 마지막 단계에 그대로 살아있는 개념.

### 소프트맥스 회귀 (Softmax Regression)

결론적으로, **다중 클래스 분류 문제**는 다음 조합으로 해결:

**소프트맥스 회귀 = 선형회귀 + 소프트맥스 + 범주형 교차 엔트로피**

- 비용함수로는 **범주형 교차 엔트로피(Categorical Cross Entropy)**라는 전용 비용함수를 사용

## 17. EDA & 데이터 전처리 — 스케일링 (Scaling)

**Garbage In, Garbage Out** — 나쁜 데이터를 넣으면 나쁜 결과가 나온다.

- **결측치**(비어 있는 값)는 수학적 계산을 불가능하게 만듦 → 그럴듯한 값으로 채우거나(대치), 해당 데이터를 삭제
- **스케일링**: 단위와 범위가 전혀 다른 데이터가 섞이면, 컴퓨터가 값이 큰 특성을 더 중요한 특성이라고 착각할 수 있음 → 정규화·표준화로 단위를 맞춰줌

### 결측치 처리

- 데이터 전처리에서 일반적으로 **가장 먼저 마주치는 문제**
- 처리 방법: **삭제** 또는 **대치**
- 문자열(범주형) 데이터는 레이블 인코딩, 원-핫 인코딩, 순서형 인코딩, 임베딩 등 다양한 방법으로 처리

### 스케일링의 두 축: 표준화 vs 정규화

#### 표준화 (Standardization)

- 모델에게 '나이'와 '연봉' 데이터를 그대로 주면 어떻게 될까? → 값의 범위가 훨씬 큰 '연봉'을 더 중요한 정보로 착각할 수 있음
- 제각각인 데이터의 단위를 공평하게 맞춰주는 작업
- 데이터의 **평균을 0, 표준편차를 1**로 변환
  - 평균 0: 모든 데이터를 0을 기준으로 맞춤
  - 표준편차 1: 각 데이터가 평균으로부터 얼마나 떨어져 있는지(표준편차)를 기준으로 데이터의 스케일을 조절

**표준정규분포 참고**: 평균 기준 ±1 표준편차 구간에 약 68.26%(34.13%+34.13%), ±2 표준편차 구간에 약 95.44%, ±3 표준편차 구간에 약 99.74%의 데이터가 분포

**특징**
- **이상치에 상대적으로 덜 민감**하고, 정규분포를 따를 때 효과적 (*이상치: 다른 값들에 비해 극단적으로 다른 값)
- 모든 특성에 공평한 영향력을 부여
- 경사하강법, SVM(Support Vector Machine), 거리 기반 알고리즘의 성능 향상에 도움

#### 정규화 (Normalization)

- 흩어져 있는 모든 데이터의 값을 **0과 1 사이의 범위**로 변환
- 데이터의 범위를 0~1로 명확하게 제한하고 싶은 경우에 활용
  - 예: 이미지 처리에서 픽셀 값은 보통 0~255로 표현되는데, 이를 정규화하면 학습이 훨씬 쉬워짐

**특징**
- 데이터의 최소/최대값을 명확히 알면 유용함
- **이상치에 민감함**

> 일반적으로는 **표준화**를 더 선호함
