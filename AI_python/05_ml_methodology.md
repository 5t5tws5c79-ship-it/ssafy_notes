## 1. 선형회귀란

- **정의**: 입력 변수와 출력 변수 사이의 관계를 직선 형태로 근사해 예측하는 통계적 방법
- 머신러닝의 기초가 되는 접근 중 하나 — 단순해 보이지만 개념적으로나 실무적으로 매우 유용

**선형회귀로 답할 수 있는 질문들** (광고 데이터 예시)
- 광고비와 매출 사이의 관계는?
- 그 관계의 강도는 얼마나 되는가?
- 어떤 매체(TV/라디오/신문)가 매출에 기여하는가?
- 미래 매출을 얼마나 정확히 예측할 수 있는가?
- 매체 간에 상호작용이 있는가?

## 2. 단순 선형회귀 (Simple Linear Regression)

- 하나의 설명변수와 하나의 반응변수 사이의 선형관계를 찾는 방법
- 데이터를 가장 잘 설명하는 직선을 찾아 ŷ(y hat) 예측에 활용

**모형 가정**: y = β₀ + β₁x + ε

> 수학적 원리를 너무 기피하면 이해의 정도가 얕아질 수밖에 없다. 직관만 알아도 괜찮지만, 수학을 잘 알면 이해의 깊이가 달라진다.
>
> "hat(^)" 표기는 **추정값**을 의미 (예: β̂는 β의 추정값)

### 최소제곱법 (Least Squares Method)

- 실제 관측값과 예측값의 잔차(residual)를 제곱해서 합한 값 = **잔차제곱합(RSS, Residual Sum of Squares)**을 최소화하는 방법
- 데이터를 가장 잘 설명하는 직선을 찾기 위해 계수 β₀, β₁을 추정

> (참고) 강의에서는 "가중치(weight)와 편향(bias)"을 통계학 용어인 **β₀(절편), β₁(기울기)**로 설명 — 같은 개념을 다른 용어로 부르는 것뿐.

- 계수를 구하는 공식: **닫힌 형태 해(closed-form solution)**가 존재함
- 원리: RSS를 미분해서 **기울기가 0이 되는 지점**을 찾는 것

### 회귀 결과표 읽는 법

라이브러리로 선형회귀를 돌리면 보통 아래 값들을 결과로 제공한다.

| 항목 | 의미 |
|------|------|
| **Coefficient (계수)** | 추정된 β 값 |
| **Std. Error (표준오차)** | 계수 추정치의 불확실성 정도 |
| **t-statistic (t 검정값)** | 계수 ÷ 표준오차 |
| **p-value** | 통계적 유의성을 나타내는 확률값 |

- **t-statistic**: 두 집단 간 평균 차이가 표본의 변동성(표준오차)에 비해 얼마나 큰지를 나타내는 값. 이 값이 클수록 평균 차이가 통계적으로 유의할 가능성이 커짐
- **p-value**: 보통 **0.05 미만이면 통계적으로 유의**하다고 판단
  - 의미: "β₁ = 0"이라는 가설(귀무가설)이 참이라고 가정했을 때, 지금 관측된 것만큼(혹은 그 이상) 극단적인 데이터가 나올 확률
  - 예: p-value가 0.00001이라는 것은 "β₁ = 0이 맞다면, 우연히 이런 데이터가 나올 확률이 0.00001이다"라는 뜻. 우연히 그럴 수도 있지만, 그 확률이 p-value만큼 낮다는 의미

> **주의**: Coefficient(계수)의 숫자 크기만 보고 "관계가 크다/작다"를 말할 수 없음! 계수가 0에 가깝다고 해서 관계가 없는 게 아님 (단위의 문제 때문). **관계의 유의성은 반드시 p-value로 판단해야 함.**
>
> t-statistic이 커질수록 p-value는 작아지는 관계.

### 광고 데이터 — 단순선형회귀 결과 해석 (예시)

**모형**: 판매량 ~ TV 광고비

| 구분 | Coefficient | Std. Error | t-statistic | p-value |
|------|-------------|------------|--------------|---------|
| Intercept (β̂₀) | 7.0325 | 0.4578 | 15.36 | < 0.0001 |
| TV (β̂₁) | 0.0475 | 0.0027 | 17.67 | < 0.0001 |

**계수 해석**
- **절편(Intercept) = 7.03** → TV 광고비가 0이어도, 기본적으로 평균 판매량은 7.03백만원
- **TV 광고비 계수 = 0.0475** → TV 광고비를 1단위(1백만원) 늘리면, 평균 매출이 약 0.0475 × 1(백만원) = **4.72만원 증가**

**유의성 검정**: 계수의 p-value < 0.0001 (매우 작음, ≪ 0.05) → 통계적으로 매우 유의함 → **TV 광고비와 매출 간 관계 존재**

**모형 적합도**: R² 값이 높을수록, 1에 가까울수록 좋음
- R² = 0.612 → **판매량 변동의 약 61%를 광고비로 설명 가능**

## 3. 다중 선형회귀 (Multiple Linear Regression)

- 피처(설명변수)가 **여러 개**로 확장된 회귀 분석 기법
- 여러 독립변수를 동시에 고려하여 종속변수 y와의 관계를 구함

**모형**: 절편 β₀와, β₁, β₂, ..., βₙ (각 피처에 대한 계수)를 학습해야 함

**계수 해석**: 다른 변수들을 모두 고정한 채, xⱼ를 1단위 증가시켰을 때 y가 평균적으로 βⱼ만큼 움직임 (편미분 관점의 해석)

> RSS(잔차제곱합) 계산법은 단순선형회귀와 동일함

### 다중선형회귀의 수학적 유도 (행렬 표현)

**행렬로 표현하기**

```
y = Xβ + ε
```

- **y**: n×1 벡터 — n개의 관측치에 대한 실제값 (y₁, y₂, ..., yₙ)
- **X**: n×(p+1) 디자인 행렬(design matrix) — 첫 번째 열은 모두 1(절편 β₀를 위한 항), 나머지 p개 열은 각 피처값
- **β**: (p+1)×1 벡터 — 우리가 찾아야 할 계수들 (β₀, β₁, ..., βₚ)
- **ε**: n×1 벡터 — 각 관측치의 오차항

즉, "y = Xβ + ε"는 n개의 각 데이터 포인트에 대해 개별적으로 쓰던 식 `yᵢ = β₀ + β₁xᵢ₁ + ... + βₚxᵢₚ + εᵢ` 을, 한꺼번에 행렬 하나로 압축해서 표현한 것.

> `[개인 메모 · 시험범위 아님]` "사진 2, 나도 이해하게끔 아주 소상하게 설명해줘 — 모든 개념을 제시해줘. 베타 행렬이랑 X 행렬의 곱인 건 알겠어."
>
> **답변 (단계별로 자세히)**
>
> **① RSS를 왜 행렬로 쓰는가?**
> RSS = Σ(yᵢ − ŷᵢ)² 을 벡터로 표현하면, "벡터 (y − Xβ̂)의 각 원소를 제곱해서 다 더한 것"과 같다. 그런데 "어떤 벡터의 각 원소를 제곱해서 합하는 연산"은 수학적으로 그 벡터를 자기 자신과 **내적(dot product)**한 것과 정확히 같다. 그래서 RSS = (y − Xβ̂)ᵀ(y − Xβ̂) 로 쓸 수 있다 (앞에 전치(ᵀ)를 붙여서 곱하는 것이 바로 내적 연산).
>
> **② 전개하면 왜 4개의 항이 나오는가?**
> (y − Xβ̂)ᵀ(y − Xβ̂)를 (a−b)(a−b) = a² − ab − ba + b² 전개하듯이 풀면 yᵀy − β̂ᵀXᵀy − yᵀXβ̂ + β̂ᵀXᵀXβ̂ 가 나온다. 여기서 β̂ᵀXᵀy와 yᵀXβ̂는 사실 둘 다 **스칼라(숫자 하나)**이고, 서로 전치 관계라서 값이 완전히 같다(스칼라는 전치해도 자기 자신과 같음). 그래서 이 둘을 합치면 나중에 미분할 때 계수 "2"가 자연스럽게 붙게 된다.
>
> **③ 왜 미분해서 0으로 놓는가?**
> RSS는 β̂를 입력으로 받는 하나의 함수라고 볼 수 있다. 목표는 이 RSS(오차)를 **가장 작게 만드는** β̂를 찾는 것. 함수의 최솟값은 (아래로 볼록한 함수라면) **기울기(미분값)가 정확히 0이 되는 지점**에서 발생한다 — 경사하강법에서 "기울기가 0인 지점 = 가장 낮은 지점"이라고 배운 것과 같은 원리다. 그래서 RSS를 β̂로 미분한 식을 0으로 놓는다:
> ∂RSS/∂β̂ = −2Xᵀy + 2XᵀXβ̂ = 0
>
> **④ β̂에 대해 정리하기**
> −2Xᵀy + 2XᵀXβ̂ = 0 → 2XᵀXβ̂ = 2Xᵀy → XᵀXβ̂ = Xᵀy → **β̂ = (XᵀX)⁻¹Xᵀy**
>
> 이것이 바로 "정규방정식(닫힌 형태 해, closed-form solution)"이다 — 미분방정식을 한 번에 풀어서 β(가중치)를 계산해주는 공식.
>
> **⑤ 직관적으로 이해하기**
> XᵀX는 "X 행렬을 자기 자신과 곱해서 만든 정사각 행렬"이고, 이 행렬의 역행렬이 존재해야만(즉 피처들끼리 심하게 종속적이지 않아야만) 이 공식을 계산할 수 있다(역행렬이 없으면 앞서 배운 SVD 등으로 우회). 전체 식 (XᵀX)⁻¹Xᵀy는 기하학적으로 "y라는 벡터를, X가 만들어내는 공간(초평면) 위로 수직으로 투영(projection)시켰을 때 필요한 계수 β̂를 계산하는 것"이라고 해석할 수 있다.

**시각화**

> `[개인 메모 · 시험범위 아님]` 시각화하면, 우리 모델은 피처(feature) = n차원 공간 안의 **초평면(hyperplane)**으로 나타난다.

- 피처가 1개면 직선(2차원 평면 위의 선), 피처가 2개면 평면(3차원 공간 위의 평면), 피처가 3개 이상이면 **초평면(hyperplane)**

### 광고 데이터 — 다중선형회귀 결과 해석 (예시)

**모형**: 판매량 ~ TV + 라디오 + 신문 광고비

| 구분 | Coefficient | Std. Error | t-statistic | p-value |
|------|-------------|------------|--------------|---------|
| Intercept | 2.939 | 0.3119 | 9.42 | < 0.0001 |
| TV (β̂₁) | 0.046 | 0.0014 | 32.81 | < 0.0001 |
| radio (β̂₂) | 0.189 | 0.0086 | 21.89 | < 0.0001 |
| newspaper (β̂₃) | -0.001 | 0.0059 | -0.18 | 0.8599 |

- **TV, 라디오 광고비**는 매출 증가에 **유의미한 관계**를 가짐 (각 p-value가 매우 낮음 ≪ 0.05)
- **신문 광고비**는 통계적으로 **유의하지 않음** (p-value = 0.8599 > 0.05) → 매출과의 관계가 거의 없음, 거의 랜덤(무작위)에 가까운 관계로 볼 수 있음

**모형 적합도**: R² = 0.897 → 모델 설명력이 매우 높음. 단순선형회귀 결과(R²=0.612)와 비교했을 때 크게 향상된 예측력

## 4. 선형회귀 사용 시 주의사항

### 훈련 데이터에서의 성능

- 학습에 사용된 훈련 데이터는 (모델이 그 데이터에 맞춰졌기 때문에) 피팅이 잘 되어 있을 것
- 따라서 **훈련 데이터에서의 성능만으로 평가하면, 실제 테스트(실전) 성능을 과대평가할 가능성이 높음**

### 상관관계 vs 인과관계 (다시 강조)

- 선형회귀 분석 시, "아이스크림 소비량"과 "상어에 물리는 사건" 사이에 **인과관계가 있다고 주장해서는 안 됨**
- 둘은 단지 **상관관계**가 있을 뿐 (제3의 변수인 "더운 날씨"가 공통 원인)

## 5. 로지스틱 회귀 (Logistic Regression)

**로지스틱 회귀는 어떻게 작동할까?**

### 분류의 정의

- **분류(Classification)**: 정해진 범주 중 하나로 지정하는 것
- **범주형 변수**: 수치의 크고 작음이 아니라, 유한한 범주로 표현되는 변수

### 분류 함수의 목표

- x가 어떤 범주에 속하는지 예측하는 것
- 단순히 범주를 딱 찍는 것보다, **확률을 추정**하는 것이 더 유용할 때가 많음

### 예시 — 신용카드 연체

- 연체자는 신용카드 **사용량(Balance)이 높은 구간**에 몰려 있는 경향
- 연체하지 않은 사람은 사용량이 **낮은 쪽**에 몰려 있는 경향
- **소득(Income)**은 연체 여부와 뚜렷한 상관관계가 보이지 않음

### 이런 분류 문제를 선형회귀로 풀면 안 될까?

→ 안 됨. **선형회귀는 확률 범위(0~1)를 벗어나는 값을 내놓을 수 있어서 문제가 발생**함

### 분류 문제에서 선형회귀의 대안 — 로지스틱 회귀

- **시그모이드(Sigmoid) 함수**를 활용해 0~1 범위 내의 확률값 예측을 보장
- 순서가 없는 범주를, 확률로 직접 예측하는 적절한 분류 방법
- 시그모이드는 기울어진 **S자 모양**의 함수
- z(선형회귀식)를 시그모이드 함수에 대입하면 → **로지스틱 회귀**

### 로지스틱 함수와 선형회귀의 관계

**로지스틱 함수는 선형회귀 식을 내포하고 있음**

- **오즈(Odds)**: 성공(y=1)할 확률이 실패(y=0)할 확률에 비해 몇 배 더 높은가를 나타냄
- **로짓 변환(Logit Transform) = 로그 오즈(Log-Odds)**: 로그(성공확률 / 실패확률)
- **로그 오즈 = 가중치×x + 편향** (선형식) — 로짓 변환을 하면 다시 선형회귀 형태로 표현 가능해짐

> **로지스틱 모형 = 선형 모형식 + 시그모이드 함수의 결합**이며, 로짓 변환을 하면 다시 선형회귀 모형식으로 표현할 수 있음

## 6. 최대우도추정 (MLE, Maximum Likelihood Estimation)

확률을 추정하는 모델(로지스틱 회귀)의 형태를 결정했으니, 이제 이 모델의 가중치와 편향(β)을 추정하는 방법을 알아볼 차례.

### 우도(Likelihood)란?

- **우도**: 현재의 확률함수가 데이터를 얼마나 잘 설명하는지를 나타낸 지표
- 모델 학습은 **우도 값을 최대화**하는 것이 목표 → 이를 **최대우도추정(MLE)**이라고 함

**우도 함수 (이진 분류)**

```
maximize L(β) = Π p(xᵢ; β)  (i: yᵢ=1인 경우)  ×  Π (1 − p(xⱼ; β))  (j: yⱼ=0인 경우)
   β

참고: p(xᵢ; β) = e^(β₀+β₁xᵢ) / (1 + e^(β₀+β₁xᵢ))
```

### 로그 우도 (Log-Likelihood)

- 우도는 여러 확률의 **곱**으로 정의되기 때문에, 계산과 미분이 어려움
- 양변에 **로그(log)**를 취해서 곱셈을 덧셈으로 변환 → **로그 우도(log-likelihood)**를 만들어 이를 최대화

```
maximize log L(β) = Σ [yᵢ·log p(xᵢ; β) + (1−yᵢ)·log(1 − p(xᵢ; β))]
   β         i=1~n
```

> 로그는 **단조함수(monotone function)**이기 때문에, 로그를 씌워도 log L(β)를 최대화하는 β의 위치는 원래 L(β)를 최대화하는 β의 위치와 동일함

### 최적화 방법

- 로그 우도를 β로 미분해서 0이 되는 지점을 찾아, **수치적 최적화**를 통해 β들을 구해나감
- 선형회귀처럼 **닫힌 형태 해(closed-form solution)가 없음** → **경사하강법**을 통해 풀어야 함

> (참고) 머신러닝에서 로그의 밑(base)은 보통 **e**(자연로그)를 사용 — 미분 시 계산이 편리해지기 때문으로 보임

### 신용카드 연체 데이터 — 로지스틱 회귀 결과 해석 (예시)

**모형**: 신용카드 사용량(Balance) → 연체 여부(Default)

| 구분 | Coefficient | Std. error | z-statistic | p-value |
|------|-------------|------------|--------------|---------|
| Intercept | −10.6513 | 0.3612 | −29.5 | < 0.0001 |
| balance | 0.0055 | 0.0002 | 24.9 | < 0.0001 |

**계수 해석 시 주의**

> ⚠️ "Balance가 1단위 증가할 때, 연체 확률이 0.0055 증가한다"고 해석하면 **틀림!**

- 연체 확률이 증가한다는 **방향**은 맞지만, 정확한 의미는 **로짓(log-odds)이 0.0055만큼 증가한다**는 뜻
- 실제 확률은 시그모이드 함수를 통과하기 때문에, 로짓 증가량이 그대로 확률 증가량이 되지 않음 (비선형적 관계)

**계산 예시**
- balance = 1000일 때: p(X;β̂) = e^(−10.6513+0.0055·1000) / (1+e^(−10.6513+0.0055·1000)) = **0.006**
- balance = 2000일 때 (입력값 2배 증가): p(X;β̂) = e^(−10.6513+0.0055·2000) / (1+e^(−10.6513+0.0055·2000)) = **0.586**

→ 입력값은 2배 증가했지만, **예측 확률값은 약 97배 증가**함 (0.006 → 0.586). "로짓은 선형적으로 증가하지만, 확률은 시그모이드를 거치며 비선형적으로 변한다"는 것을 보여주는 예시

> 여러 입력(피처)을 추가해서 다변수 모형으로 확장하면, 회귀 계수들을 통해 연체할 확률을 계산할 수 있음

### 학습 방법

- 선형회귀와 마찬가지로 로지스틱 회귀도 **순차적으로 파라미터(모수)를 조정해나가며 찾는 방식**(경사하강법 계열)으로 학습함

## 7. 얕은 신경망 (Shallow Network)

- **입력층 - 은닉층(1개) - 출력층**으로 구성된, **은닉층을 1개만 가진** 신경망 구조

**장점**
- 복잡한 비선형 패턴까지 학습 가능
- 단순 선형 모델 대비 표현력 향상
- 구조가 간단해 학습 속도가 빠르고 구현이 쉬움
- 데이터가 충분치 않아도 과적합 위험이 비교적 낮음

**사용 예시**
- 간단한 분류 및 회귀 문제
- XOR처럼 비선형 경계(decision boundary)가 필요한 문제

### 활성화 함수 (Activation Function)

```
y = f[x, φ] = φ₀ + φ₁·a[θ₁₀+θ₁₁x] + φ₂·a[θ₂₀+θ₂₁x] + φ₃·a[θ₃₀+θ₃₁x]
```

- 여기서 **a[ ]**가 바로 **활성화 함수(activation function)**

**대표적인 활성화 함수 — ReLU (Rectified Linear Unit)**

```
a[z] = ReLU[z] = 0   (z < 0일 때)
              = z   (z ≥ 0일 때)
```

- 입력 구간을 나눠서, **조각별로 선형인 함수(piecewise linear function)**를 만들어주는 함수

### 히든 유닛 (Hidden Units)

식을 두 부분으로 나눠서 생각하면:

```
y = φ₀ + φ₁h₁ + φ₂h₂ + φ₃h₃
```

여기서 히든 유닛(hidden units)은:
- h₁ = a[θ₁₀ + θ₁₁x]
- h₂ = a[θ₂₀ + θ₂₁x]
- h₃ = a[θ₃₀ + θ₃₁x]

**작동 원리**
1. 각각의 입력이 들어와서 **선형식**이 만들어짐 (θ₀ + θ₁x 형태)
2. 여기에 **ReLU(활성화 함수)를 씌움** → 그게 바로 히든 유닛(h₁, h₂, h₃)
3. 각 히든 유닛에 φ(파이, 그리스 문자로 가중치를 나타냄)를 곱함 → 이때 **꺾인 점의 위치 자체는 바뀌지 않고, 값(높이)만 바뀜**
4. 이렇게 만들어진 함수 3개를 모두 **더하면** 최종 결과 그래프가 나옴 — 이게 바로 신경망(뉴럴 네트워크), 그중에서도 **얕은 신경망(Shallow Neural Network)**

> `[개인 메모 · 시험범위 아님]` 활성화 함수가 없으면 어떻게 될까? → 아무리 복잡한 식이 들어와도 결국 wx+b 형태(선형)로 회귀(collapse)해버리기 때문에, **층을 여러 개 쌓는 이유 자체가 없어짐**

- 각 파라미터는 "출발 노드의 값 × 가중치"를 계산해서 출력 노드에 더해주는 방식으로 작동

### 보편적 근사 정리 (Universal Approximation Theorem)

- 히든 유닛이 **충분히 많으면**, 임의의 1차원 함수를 원하는 정확도로 정확하게 근사할 수 있음 (조각별 선형 구간, piecewise linear region이 많아지기 때문)
- 정확히는: **히든 유닛을 충분히 많이 갖는다면, 얕은 신경망(1개의 은닉층만 가진 신경망)도 임의의 연속함수를 임의의 정밀도로 근사할 수 있음**

> 흔히 "레이어(층) 숫자가 많아야 (딥러닝이) 좋다"고 생각하기 쉽지만, 이론적으로는 **얕은(shallow) 신경망만으로도 근사가 가능하다**는 뜻

### 확장 1 — 출력이 여러 개(다중 출력)일 때

- 출력이 여러 개면, **꺾인 점(breakpoint)의 위치는 여전히 같지만, 그 지점에서의 값은 (출력마다) 달라짐**

### 확장 2 — 입력이 여러 개(다중 입력)일 때

- 활성화 함수에 들어가기 전 단계가 바로 **다중 선형회귀(multiple linear regression)** 형태가 됨
- 입력이 2개가 되면, 이제는 **평면(2차원 공간)** 위에서 생각해야 함
  - 평면에 ReLU를 적용하면, 0 미만인 부분의 등고(값)가 모두 날아감(0이 됨)
  - ReLU가 적용된 평면에 상수(φ)를 곱함
  - 이렇게 만들어진 여러 개를 마지막에 합치면, 어떠한 **서페이스(surface, 표면)**가 만들어짐
- 노드(히든 유닛)가 충분히 많으면, 매우 복잡한 서페이스도 근사할 수 있음 → 이 개념을 **n차원으로 확장**하면:
  - **임의의 차원에 대해, 임의의 초표면(hypersurface)을 초평면(hyperplane)들의 조합으로 근사 가능함**

## 8. 깊은 신경망 (Deep Neural Network)

- **여러 개의 얕은 신경망을 하나로 합성(composition)**한 구조
- 비유: **종이 접기(folding)** — 접는 횟수(층수)가 늘어날수록 표현할 수 있는 패턴이 기하급수적으로 복잡해짐
- 얕은 신경망(shallow)에 비해, 깊은 신경망(deep)의 **표현력**이 훨씬 커짐

**예시**: 총 6개의 히든 유닛을 사용할 때
- **얕은 구조 (1-6-1: 은닉층 1개에 6개 노드)**보다, **깊은 구조 (1-3-3-1: 은닉층 2개에 각 3개씩 노드)**로 나눠 배치했을 때 표현력(만들어낼 수 있는 조각별 선형 구간의 개수)이 더 높음

> 딥러닝의 표현력이 더 높으므로, 그래서 딥러닝(깊은 신경망)을 사용함
>
> 얕은 신경망이 표현을 못 하는 건 아니지만(이론상 가능), **계산량 대비 표현의 효율성**이 낮음 → 그래서 실무에서는 **깊은 층을 가진 딥 뉴럴넷**을 사용

### 신경망 피팅(학습) 방법론 — 개요

- **손실함수(Loss Function)**: 모델이 얼마나 잘했는지/못했는지를 측정하는 함수
- 신경망 학습의 목표: **손실함수를 최소화하는 파라미터(가중치)를 찾는 것**
- 손실을 가장 작게 만드는 파라미터를 **φ̂(파이햇)**이라고 부름 (추정된 최적 파라미터)

## 9. 경사하강법과 최적화

### 손실함수의 지형(Loss Landscape)

- 선형회귀에서 손실함수는 RSS(=MSE, 평균제곱오차)였음
- 손실값의 크기를 등고선(contour)으로 나타냈을 때: **밝을수록 손실이 크고, 어두울수록 손실이 작음**

### 경사하강법 (다시 정리)

- 손실함수 값이 **줄어드는 방향**으로 파라미터를 이동하는 과정
- 경사를 따라 내려가다가 더 이상 내려갈 곳이 없는 지점(최소점)에 도달하면, 그게 데이터에 가장 잘 핏(fit)되는 모델
- **미분값의 반대 방향**으로 이동하면 됨 — 그것이 바로 "경사 하강"

**경사하강 알고리즘**
1. 기울기 계산: 각 파라미터에 대해 편미분해서 벡터로 나열
2. 미분값의 **반대 방향**으로, 학습률(learning rate)에 맞는 만큼 이동
3. 최솟값에 도달할 때까지 반복

### 컨벡스(Convex) vs 넌컨벡스(Non-convex) 최적화 문제

| 구분 | 설명 | 예시 |
|------|------|------|
| **컨벡스(Convex) 함수** | 곡선이 항상 U자 형태로 아래로 볼록함. 그래프 위 임의의 두 점을 잇는 직선이 항상 그래프 위쪽(또는 그래프 위)에 위치 | 2차함수 |
| **논컨벡스(Non-convex) 함수** | 봉우리와 골짜기(오목한 구간)가 섞인 모양. 두 점을 이은 직선이 그래프 아래로 내려가는 구간이 생김 | 3차함수 |

- **논컨벡스 함수는 로컬 미니마(local minima) 문제에 마주칠 수 있음** → 최적화가 어려움

### 확률적 경사하강법 (Stochastic Gradient Descent, SGD)

- 논컨벡스 문제에서는, 일반적인 경사하강법이 **로컬 미니마에 빠지기 쉬움**
- 매 스텝마다 **전체 데이터**에 대한 미분값을 구해서 업데이트 → 스텝별 계산량이 매우 많음
- **대안**: 전체 데이터를 한 번에 쓰는 대신, **무작위로 선택한 데이터 샘플(미니배치)**만 사용 → **확률적 경사하강법(SGD)**

**업데이트 방식의 차이점**
- 무작위 확률로 샘플된 일부 데이터(배치)만 사용하여 기울기 계산
- 데이터를 쪼개서 쓰기 때문에, 이동 경로가 조금 더 **노이즈가 섞인(noisy) 스텝**이 됨

> `[개인 메모 · 시험범위 아님]` 개인적 질문: 이것도 결국 로컬 미니마 문제를 회피하지 못하는 건 동일한 거 아닌가?
>
> **답변**: 정확히 말하면, SGD가 로컬 미니마 문제를 **완전히 없애주는 건 아니다** — SGD도 여전히 지역 최솟값에 걸릴 가능성이 이론적으로는 존재한다. 다만 미니배치를 사용하면 매 스텝의 기울기 계산에 자연스러운 **노이즈**가 섞이게 되는데, 이 노이즈 덕분에 얕은 지역 최솟값이나 **안장점(saddle point)**처럼 "기울기는 0이지만 진짜 최솟값은 아닌 지점"에서 상대적으로 더 쉽게 빠져나올 수 있다. 즉 SGD는 로컬 미니마 문제를 원천 차단하는 게 아니라, 노이즈라는 부수 효과(side effect)를 활용해서 그 위험을 **상대적으로 줄여주는** 정도라고 이해하면 된다. (강의 자료의 표현대로: "로컬 미니마에 빠질 위험이 상대적으로 적어질 것 — 어차피 메모리(VRAM) 공간 제약 때문에 배치로 쪼개는 김에, 그 부수 효과를 활용하는 것")

**SGD의 특성**
- 일부 배치로 기울기를 계산하기 때문에 노이즈가 생기는데, 이 **노이즈가 안장점(saddle point)이나 로컬 미니마에서 빠져나오는 데 도움**이 됨
- 평균적으로는 **올바른 방향**을 가리키도록 수렴함
- **계산 비용 절감** — 큰 데이터셋에서 효율적인 학습이 가능
- 풀배치(전체 데이터 사용)처럼 매끄럽게 수렴하지 않고, 무작위성 때문에 더 지터리(jittery, 들쭉날쭉)하게 움직임
- 전역 최솟값 근처의 좋은 해에 도달할 수 있지만, **컨벡스 문제에서는 풀배치 경사하강법보다 수렴이 늦을 수 있음**

## 10. 역전파 (Backpropagation)

### 역전파가 필요한 이유

- 네트워크의 파라미터의 미분값을 어떻게 구할까? 레이어별로 파라미터들이 존재하고, 서로 영향을 미침

### 합성함수의 미분 — 연쇄법칙 (Chain Rule)

- 핵심 아이디어: **합성함수의 변화율 = 바깥쪽의 변화율 × 안쪽의 변화율**

> 연쇄법칙은 꼭 따로 복습해둘 것 (역전파 이해의 전제 조건)

### 역전파란?

**출력 오차를 기준으로 그래프를 거꾸로 따라가며, 연쇄법칙으로 각 노드(파라미터 포함)의 미분값을 계산하는 절차**

**절차**
1. 각 단계별 계산을 분해
2. 각 레이어별 값(fₖ)을 계산
3. 각 레이어별 값(fₖ)에 대한 출력 손실(ℓᵢ)의 미분을 구함

**예시 (은닉층 3개짜리 네트워크)**

순전파(forward) 계산 순서:
```
f₀ = β₀ + Ω₀xᵢ
h₁ = a[f₀]
f₁ = β₁ + Ω₁h₁
h₂ = a[f₁]
f₂ = β₂ + Ω₂h₂
h₃ = a[f₂]
f₃ = β₃ + Ω₃h₃
ℓᵢ = l[f₃, yᵢ]
```

역전파(backward) 계산 — 출력(손실)에서부터 거꾸로 미분을 구해나감:
```
∂ℓᵢ/∂f₂ = (∂h₃/∂f₂)(∂f₃/∂h₃)(∂ℓᵢ/∂f₃)
∂ℓᵢ/∂f₁ = (∂h₂/∂f₁)(∂f₂/∂h₂) × [ (∂h₃/∂f₂)(∂f₃/∂h₃)(∂ℓᵢ/∂f₃) ]
∂ℓᵢ/∂f₀ = (∂h₁/∂f₀)(∂f₁/∂h₁) × [ ... 위에서 구한 값을 재사용 ... ]
```

> 핵심 포인트: 뒤쪽(출력에 가까운) 레이어에서 이미 계산해 둔 미분값을, 앞쪽(입력에 가까운) 레이어의 미분을 구할 때 **그대로 재사용**한다 — 그래서 "역"전파. 매번 처음부터 다시 계산하지 않고, 이미 구한 결과를 재활용하기 때문에 효율적임.

### 역전파, 아주 쉽게 설명하면?

> 위 수식이 하나도 이해가 안 될 수 있다. 비유로 다시 설명하면:
>
> 공장에 여러 명의 작업자가 한 줄로 서서, 앞사람이 만든 반제품을 받아 자기 몫의 작업을 더한 뒤 다음 사람에게 넘기는 **조립 라인**을 상상해보자. 마지막 사람이 완성품을 검사했더니 "불량품"이 나왔다(= 손실, loss). 이제 "누가 얼마나 잘못했는지"를 알아내야 다음번에 더 잘 만들 수 있을 것이다.
>
> 이때 가장 자연스러운 방법은, **맨 마지막 사람부터 거꾸로 거슬러 올라가며** "내가 받은 반제품 대비, 내가 추가한 작업이 최종 불량에 얼마나 영향을 줬는가"를 하나씩 따져보는 것이다. 마지막 사람의 책임을 계산했으면, 그 정보를 바로 앞사람에게 넘겨준다. 앞사람은 "내가 넘긴 반제품이 뒷사람의 결과에 이 정도 영향을 줬다"는 정보를 받아서, 자기 작업이 최종 불량에 얼마나 기여했는지를 계산한다. 이 과정을 맨 처음 사람까지 반복한다.
>
> 신경망도 똑같다. **마지막 층(출력에 가장 가까운 층)의 오차 책임을 먼저 계산**하고, 그 계산 결과를 바로 이전 층으로 "전달"해서, 이전 층은 그 정보를 받아 자기 파라미터의 책임을 계산한다. 이렇게 **출력에서 입력 방향으로(거꾸로) 책임(=미분값)을 전달해나가는 것**이 역전파(Back-propagation)다. 매번 전체를 처음부터 다시 계산하지 않고, 바로 다음(뒤쪽) 층에서 이미 계산해 둔 값을 그대로 이어받아 쓰기 때문에 계산이 효율적이다.

### 그럼 히든레이어가 많을수록 항상 이득 아닌가?

**아니다.** 층이 너무 깊어지면 **학습 자체가 어려워지는** 문제가 발생한다 — **그래디언트 배니싱(Vanishing Gradient, 기울기 소실)**

| 관점 | 내용 |
|------|------|
| **깊이(depth)가 깊어지면** | 표현력(expressiveness)은 커짐 |
| **하지만** | 학습이 더 어려워짐 (기울기 소실 위험) |

> **"공짜 점심은 없다(No Free Lunch)"** — 깊이를 늘리는 것이 표현력 측면에서는 이득이지만, 그만큼 학습 난이도라는 대가가 따른다.
>
> 현대의 신경망(딥러닝 모델)은 깊이가 굉장히 깊은데, 여전히 기울기 소실(vanishing gradient) 문제에 부딪힐 수 있다.
