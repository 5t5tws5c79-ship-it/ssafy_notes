## 1. 데이터 분석 과정에서 전처리의 비중

**데이터 분석 과정에는 모델링보다 전처리에 훨씬 많은 시간이 소요된다.**

> `[개인 메모 · 시험범위 아님]` 데이터 전처리가 미흡할 시 **모델 누수(data leakage)**가 발생할 수 있다.

- **모델링은 전처리를 마친 데이터를 바탕으로 진행**된다.
- **데이터가 정확할수록** 분석과 집계 과정의 오류가 줄어든다.
- **잘못된 데이터를 입력하면 결과도 잘못될 수 있다.** (Garbage In, Garbage Out)

**데이터 전처리란?** 결측치 보정, 이상치 처리, 정규화, 인코딩을 수행하는 작업.

## 2. 왜 시각화가 필요한가 — 숫자 표 vs 그림

- **숫자로 나열된 표**는 한눈에 패턴이 잘 보이지 않는다.
- **그림(차트)**은 한눈에 패턴이 보인다.

**데이터의 특성에 적합한 차트를 고르면** 비교, 추이 분석, 분포 파악이 용이해진다.

- **차트를 잘못 지정하면 데이터 정보를 왜곡하거나 흐리게 만들기 때문에 유의해야 한다.** (예: 시계열 데이터를 막대로 그리면 추이가 잘 안 보임)

### 차트를 선택하는 법

| 데이터 특성 | 추천 차트 | 용도 | 예시 |
|-------------|-----------|------|------|
| **범주별 크기 비교** | 막대그래프 (bar) | 값 비교 | 지역별 매출 |
| **시간에 따른 변화** | 꺾은선그래프 (line) | 추이 확인 | 월별 매출 변화 |
| **두 변수의 관계** | 산점도 (scatter) | 관계 확인 | 단가와 수량 |
| **값의 분포와 빈도** | 히스토그램 (hist) | 분포 확인 | 수량 분포 |
| **범주별 편차와 이상치** | 상자그림 (boxplot) | 산포와 이상치 확인 | 지역별 매출 분포 |

> - **편차(Deviation)**: 각 값이 평균과 같은 기준값에서 떨어진 정도
> - **산포(Dispersion)**: 데이터가 넓게 퍼져 있는 정도
> - **시계열(Time Series)**: 시간 순서에 따라 기록된 데이터

### 기본 차트 정리

| 차트 | 용도 |
|------|------|
| **Bar (막대)** | 범주별 비교 |
| **Line (선)** | 시간에 따른 변화 |
| **Scatter (산점도)** | 상관관계 확인 |
| **Hist (히스토그램)** | 분포 확인 |

## 3. Matplotlib이란?

**파이썬에서 가장 널리 사용되는 시각화 라이브러리.**

- **NumPy를 기반**으로 다양한 형태의 차트와 그래프를 생성할 수 있게 해준다.

### 한글 폰트 깨짐 문제

Matplotlib은 **기본적으로 한글 폰트를 지원하지 않아**, 한글이 깨져서 표시되는 문제가 흔히 발생한다.

> `[개인 메모 · 시험범위 아님]` 한글 폰트 안 깨지게 설정하는 게 은근 자주 짜증나는 포인트다.

**해결책:** 한글 폰트(예: **"맑은 고딕"**)를 명시적으로 지정해줘야 한다.

```python
import matplotlib.pyplot as plt

plt.rcParams['font.family'] = 'Malgun Gothic'   # 윈도우 기준 한글 폰트 설정
plt.rcParams['axes.unicode_minus'] = False       # 마이너스(-) 기호 깨짐 방지
```

## 4. Matplotlib 실습 예시

> 아래 항목들은 수업에서 "이런 게 있다" 정도로 가볍게 다룬 내용이라, **세부 옵션을 전부 외울 필요는 없다.** 필요할 때 다시 찾아보는 용도로 정리해둔다.

### 여러 그래프를 하나의 차트에 표시하기

```python
x = np.linspace(0, 2*np.pi, 100)
y1 = np.sin(x)
y2 = np.cos(x)
y3 = np.sin(x * 5)

plt.plot(x, y1, label='sin(x)', color='blue')
plt.plot(x, y2, label='cos(x)', color='red')
plt.plot(x, y3, label='sin(5x)', color='green')

plt.title("여러개의 그래프")
plt.xlabel("x")
plt.ylabel("y")
plt.legend()          # 범례 표시 — 각 선이 어떤 데이터인지 알려주는 상자
plt.grid(alpha=0.2)   # 격자 표시, alpha는 격자선의 투명도
plt.show()
```

### 스타일과 색상 커스터마이징

```python
plt.plot(x, y, color='red', linestyle='--', linewidth=2, marker='o')
plt.title("월별 매출 추이", fontsize=16)
plt.xlabel("월", fontsize=12)
plt.ylabel("매출(만원)", fontsize=12)
plt.grid(alpha=0.3)
plt.show()
```

| 옵션 | 역할 |
|------|------|
| `color` | 선의 색상 |
| `linestyle` | 선의 모양 (`--`는 점선) |
| `linewidth` | 선의 굵기 |
| `marker` | 데이터 포인트에 표시할 마커 모양 (`'o'`는 동그라미) |
| `label` | 범례에 표시될 이름 |
| `fontsize` | 글자 크기 |

> 요약하면: 하나의 차트 위에 `plt.plot()`을 **여러 번 호출**해서 여러 데이터를 겹쳐 그릴 수 있고, `title`/`xlabel`/`ylabel`/`legend`/`grid` 같은 함수들로 **꾸밀 수 있다.**

### 히스토그램 사용 시 주의사항

**히스토그램은 데이터에 결측치(NaN)가 있으면 에러가 난다.** 히스토그램을 그리기 전에 **반드시 결측치를 제거**해야 한다.

```python
df['age'].dropna().hist()   # 결측치를 제거한 뒤 히스토그램 그리기
```

## 5. 데이터 전처리 (Data Preprocessing)

**원본 데이터를 분석과 모델 학습에 맞게 다듬는 작업.**

### 데이터 분석의 진행 순서

**데이터 불러오기 → EDA(탐색적 데이터 분석) → 전처리 → 분석 → 결과** 순으로 진행한다.

- **입력 데이터의 품질은 분석과 모델 결과에 직접적인 영향을 준다.**
- **원본 데이터는 그대로 보존**하고, **전처리한 사본을 사용**하는 것이 원칙이다. (원본을 훼손하면 나중에 처리 방식을 바꾸고 싶을 때 되돌릴 수 없기 때문)

### 전처리의 4대 작업

| 작업 | 문제 상황 | 처리 방법 |
|------|-----------|-----------|
| **결측치** | 단가가 비어 있음 | 평균이나 중앙값으로 대체 |
| **이상치** | 수량이 99로 입력됨 (비정상적으로 큰 값) | 값 확인 후 보정하거나 제거 |
| **정규화** | 단가와 수량의 범위가 다름 | 같은 범위로 변환 |
| **인코딩** | 메뉴가 문자열로 저장됨 | 숫자 형식으로 변환 |

> **인코딩(Encoding)이란?** **범주형 데이터를 숫자로 변환**하는 것.

### 전처리 4대 작업 — 정의 정리

| 작업 | 설명 |
|------|------|
| **결측치 처리** | 비어있는 값을 **채우거나** 해당 데이터를 **제거** |
| **이상치 처리** | 다른 값보다 지나치게 크거나 작은 값을 **확인하고 처리** |
| **정규화** | 서로 다른 값의 범위를 **같은 기준으로 조정** |
| **인코딩** | 범주형 데이터를 **숫자로 변환** |

## 6. 결측치·이상치 찾기

```python
df.isnull().sum()   # 컬럼별 결측치 개수 확인
df.describe()        # 통계 정보(평균, 표준편차, 최솟값, 최댓값 등)를 확인 — 이상치 판단에 참고
```

### 결측치 채우기

**`fillna()`**로 채우되, **평균/중앙값 등 대체값을 선택하기 전에 그 값이 데이터에 적합한지 확인**해야 한다.

- **평균은 이상치에 끌려갈 수도 있으므로**, 중앙값이 더 적합한 경우가 많다. **다만 이건 데이터를 면밀히 탐색한 뒤 판단해야 한다.** (무조건 중앙값이 정답은 아님)
- **최빈값**으로 채우는 것도 괜찮은 방법이다. (특히 범주형 데이터의 경우)

```python
df['단가'].fillna(df['단가'].median(), inplace=True)   # 중앙값으로 채우기
df['메뉴'].fillna(df['메뉴'].mode()[0], inplace=True)   # 최빈값으로 채우기
```

### 여러 컬럼을 조합해서 결측치 채우기

**두 개의 데이터를 조합해서 하나의 컬럼의 결측치를 채워야 할 경우도 있다.** 예를 들어 **"성별별 나이(Age) 평균"**으로 나이 결측치를 채우는 경우처럼, 단순히 전체 평균이 아니라 **관련 있는 다른 컬럼으로 그룹을 나눈 뒤 그 그룹의 평균/중앙값으로 채우는 방식**이 더 정확할 수 있다.

```python
df['age'] = df.groupby('sex')['age'].transform(lambda x: x.fillna(x.median()))
```

## 7. 특성 공학 (Feature Engineering)

기존 컬럼들을 조합하거나 가공해서 **새로운 의미 있는 컬럼(특성)을 만들어내는 작업.**

**예시 — Family 컬럼 만들기:** 형제자매(sibling/spouse) 수와 부모자식(parent/child) 수를 더해서 **"가족 수(family size)"**라는 새로운 컬럼을 만들 수도 있다.

```python
df['family_size'] = df['sibsp'] + df['parch']
```

## 8. 인코딩 (Encoding)

**범주형 데이터를 숫자로 변환**하는 작업.

### 단순 이진 인코딩

```python
df['sex'] = df['sex'].map({'male': 1, 'female': 0})   # 남자는 1, 여자는 0으로 인코딩
```

### 원-핫 인코딩 (One-Hot Encoding)

> `[개인 메모 · 시험범위 아님, 다만 강사가 언급함]` 범주형 데이터는 **원-핫 인코딩**으로 처리할 수도 있다.

**원-핫 인코딩이란?** 범주가 3개 이상일 때, 각 범주를 **0/1로 이루어진 별도의 컬럼으로 나눠서** 표현하는 방식. (예: `메뉴` 컬럼이 아메리카노/라떼/에이드였다면, `메뉴_아메리카노`, `메뉴_라떼`, `메뉴_에이드`라는 3개의 컬럼으로 나뉘고, 해당하는 컬럼에만 1이 들어감)

```python
pd.get_dummies(df['메뉴'])
```

> **단순 숫자 매핑(1, 0, 2...)과의 차이:** `남/여`처럼 범주가 2개뿐이고 순서·우열 관계가 없는 경우는 단순히 1/0으로 매핑해도 큰 문제가 없다. 하지만 범주가 3개 이상인데 단순히 0, 1, 2로 매핑해버리면, 모델이 이를 **"2가 0보다 크다"는 크기 관계로 잘못 해석**할 위험이 있다. 원-핫 인코딩은 이런 **범주 간에 크기·순서 관계가 없다는 것을 명확히 표현**하기 위한 방법이다.
