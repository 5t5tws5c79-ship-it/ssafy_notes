## 1. AI / ML / DL의 정의

- **AI (인공지능)**: 가장 큰 범위. 주어진 환경과 데이터를 인지·학습·추론하여 목표를 달성하도록 예측·행동·계획하는 시스템.
- **ML (머신러닝)**: AI의 하위 범주. **데이터로부터 학습**하여 목적을 달성하는 접근 방법론.
- **DL (딥러닝)**: ML의 하위 범주. **신경망 함수**를 사용한 학습 방법론.

> **AI − ML (차집합)에 해당하는 것**: 규칙 기반 시스템, 휴리스틱 기반 알고리즘 등 — 데이터로부터 "학습"하지 않는 AI도 존재한다.

## 2. 데이터와 학습의 이해

### 머신러닝의 순환 개선 루프

**데이터 → 모델 → 학습 → 평가 → (다시 데이터로 피드백)**

> **머신러닝이란?** 데이터를 이용해 모델을 학습하고, 평가 결과를 바탕으로 데이터·모델·학습 방법을 반복적으로 개선해나가는 과정.

### 왜 데이터가 중요한가

- 머신러닝은 규칙을 직접 코딩하지 않고, **데이터에서 규칙을 학습**한다.
- 데이터(피처/라벨)의 **분포와 관계**가 머신러닝의 학습 결과를 결정한다.

### 피처와 라벨

| 구분 | 정의 |
|------|------|
| **피처 (Feature)** | 모델이 예측에 사용하는 입력 정보. 예측 판단의 근거/단서 |
| **라벨 (Label)** | 모델이 예측하려는 목표값(정답). 학습의 목표값 |

**예시**

| 문제 | 피처 | 라벨 |
|------|------|------|
| 유튜브 추천 | 영상 정보(장르, 크리에이터, 조회수, 좋아요), 사용자 정보(시청 이력, 구독 채널) | 사용자 피드백(시청 여부, 좋아요/클릭 여부) |
| 스팸 메일 분류 | 메일 제목, 발신자, 단어 빈도 | 스팸 / 정상 |

## 3. 단일 피처(1D) 기반 학습

**1D = 1차원.** 피처가 하나일 때 머신러닝이 학습하는 가장 단순한 형태.

```
Income_i = f*(Years of Education_i) + ε_i
```

- 데이터셋 D: 30명의 Years of Education(피처)과 Income(라벨) 쌍
- D = {(Years of Education_i, Income_i)}, i = 1 ~ 30

| 구성 요소 | 설명 |
|-----------|------|
| **미지의 참 함수 (f\*)** | 피처와 라벨 사이의 **실제 평균 관계**. 직접 관측할 수 없고, 오차가 포함된 데이터(점)로만 관측 가능 |
| **측정오차 (ε)** | 데이터에 섞여 있는 오차. 원인: 측정 기기의 한계, 환경적 요인 등 |

**즉, 데이터 = 참 함수 + 오차 (f\* + ε)**

### 함수 후보와 학습

- 데이터를 설명하는 여러 함수 후보가 존재한다.
- 어떤 함수가 가장 잘 맞는지 **학습**해야 한다.

### 모델과 가설 공간 (Hypothesis Space)

- **학습(Learning)**: 입력 → 출력 관계를 찾는 과정. 평균적인 관계를 하나의 함수로 표현하지만, 관계를 표현할 수 있는 함수는 무수히 많다.
- **가설 공간 (Hypothesis Space)**: 관계를 표현할 수 있는 **모든 후보 함수들의 모음**. 피처 공간과 라벨 공간 위에 정의된 함수들의 집합.
  - 예: 직선을 찾기로 하면 → 무수히 많은 선형 함수들의 집합이 가설 공간
  - 곡선을 찾기로 하면 → 곡선들의 집합이 가설 공간
  - 선형회귀를 선택 → 선(직선)들의 집합에서 탐색
  - 딥러닝을 선택 → 뉴럴 네트워크 구조 자체가 가설 공간이 됨
- **모델**: 가설 공간 F에 속한 **특정 함수** f

> `[개인 메모 · 시험범위 아님]` 질문: 모델 레이어 설계가 가설공간이 되는지???

> 가설 공간은 우리가 직간접적으로 항상 설정하게 된다.

## 4. 복수 피처(2D+) 기반 학습

피처가 두 개가 되면 3차원 공간에서 표현해야 한다. 참 함수 f\*는 하나의 **서페이스(surface, 곡면)** 형태이며, 이 역시 직접 관측은 불가능하다.

> `[개인 메모 · 시험범위 아님]` 학습자 이해를 위해 2→3차원으로 먼저 확장한 뒤, 이를 다시 n차원으로 일반화하려는 흐름인 듯.

```
Income = f*(Years of Education, Seniority) + ε
```

- f\*(서페이스)를 평면, 곡면 등 다양한 형태로 가설 공간을 설정할 수 있다.
- **ε(오차)이 0으로 가는 것이 좋은 걸까?** → 아니다. **과적합(overfitting)**의 위험이 있다.

> `[개인 메모 · 시험범위 아님]` 과적합 = 훈련 데이터에 너무 핏하게 함수가 맞춰져서, 실제(새로운) 데이터에서는 예측에 못 쓰게 되는 상황.

> **'참함수'를 찾는 것이 중요함** (교수님 강조). 데이터는 원래 참함수에서 어느 정도 떨어져 있다.

### 일반적 용어 정리 및 모델 가정

```
Income = f*(Years of Education, Seniority, ...) + ε   →   Y = f*(X) + ε
```

| 개념 | 표기 | 설명 |
|------|------|------|
| Income | Y | 우리가 예측하려는 라벨(반응/목표) 변수 |
| Years of Education | X₁ | 첫 번째 피처(입력/예측) 변수 |
| Seniority | X₂ | 두 번째 피처(입력/예측) 변수 |
| i번째 피처 | Xᵢ | 다른 피처가 더 있다면 동일하게 표기 |

- 일반적인 p차원 피처(총 p개의 피처) 벡터: **X** = [X₁, X₂, ⋯, Xₚ] ∈ ℝᵖ
- 모델(함수형): f\*: ℝᵖ → ℝ,  Y = f\*(**X**) + ε
- **측정오차 ε의 가정**: 피처 X와 **독립**이며, E[ε] = 0
  - X가 커진다고 오차가 커지거나 하지 않음 (오차는 X의 변화량과 무관)
  - 측정오차의 평균은 0으로 가정함

### 왜 함수 f를 학습하는가?

1. **예측**: 잘 학습된 f가 있으면, 새로운 입력 X=x에 대해 반응/목표 Y를 예측할 수 있다.
2. **중요 특성 파악**: 피처들 X 중 어떤 특성이 Y를 설명하는 데 중요하고, 어떤 것은 덜 중요한지 알 수 있다.
3. **해석 가능성**: f의 복잡도에 따라, 각 구성 요소 Xᵢ가 Y에 어떻게 영향을 미치는지 이해할 수 있다.

## 5. 지도학습(Supervised Learning) 개요와 용어

**목표**: 처음 보는 문제도 잘 푸는 AI 만들기.

- **정의**: 입력 + 정답을 가지고 예측 규칙을 배우는 방법
- **목표**: 훈련 데이터뿐 아니라 **처음 보는 데이터**에서도 예측 성능 향상
- 예시: 어제까지의 고객 데이터로 내일 이탈할 고객을 미리 알아내기 / 기존 사기 데이터로 새로운 사기 거래 예측
- 이미지 분류 예시: 고양이/개 라벨이 붙은 훈련 데이터(입력 X + 정답 라벨 Y)로 신경망 등 알고리즘을 학습시켜 분류 모델을 만들면, 훈련에 쓰이지 않은 새로운 이미지에서도 정답을 맞출 수 있어야 한다.

### 지도학습의 두 유형

| 유형 | 조건 | 예시 |
|------|------|------|
| **회귀 (Regression)** | 예측하고 싶은 결과값이 **숫자**일 때 | 가격, 점수, 온도 등 |
| **분류 (Classification)** | 예측하고 싶은 결과값이 **범주**일 때 | 스팸/정상, 질병 유무 등 |

### 학습이란?

- 주어진 데이터에서 정답을 가장 잘 맞출 수 있도록 **모델의 규칙을 조금씩 조정**해가는 과정
- 데이터 D → 가설공간 F → 선택된 모델 f

**학습에 필요한 3가지**

| 구성 요소 | 설명 |
|-----------|------|
| **1. 데이터 (Data)** | 학습할 예시들(예: 학력-수입 쌍 30개). 입력(특성)과 정답(라벨) 쌍으로 된 모음 |
| **2. 가설 공간 (Hypothesis Space)** | 선택할 수 있는 모든 후보 함수들의 집합. "이 중에서 가장 좋은 함수를 찾아야 해" |
| **3. 선택 기준 (손실 함수)** | 어떤 함수가 더 좋은지 판단하는 척도. 예측값과 실제값의 차이를 측정 |

**학습 과정**

1. 가설공간에서 하나의 함수를 선택
2. 그 함수로 데이터의 모든 예시를 예측
3. 손실함수로 틀린 정도 계산
4. 더 적게 틀리도록 함수의 파라미터 조정
5. 반복하여 최적의 모델 완성

### 지도학습 핵심 용어

| 용어 | 설명 | 예시 |
|------|------|------|
| **특성 (Feature, x)** | 예측에 사용되는 설명 변수. 예측 함수 f의 input | 집값 예측: {지역, 평수, 방수, 연식}. 스팸 필터링: {제목, 내용 텍스트, 송신자} |
| **라벨 (Label, y)** | 맞춰야 하는 정답(실제값) | 집값, 스팸/정상 여부 |
| **예측값 (ŷ)** | 학습 과정에서 모델이 내놓은 결과(숫자 또는 범주). y의 추정치 | — |
| **오류 (Error)** | 예측값(ŷ)과 라벨(y)의 차이: ŷ − y. 손실 함수로 계산 | — |

> **오류 ≠ 측정 오차.** 예측값과 실제값의 차이(오류)를 줄이는 것이 지도학습의 목표!

> **참고**: "ŷ − y가 ε인가요???" → 아닙니다 (매우 중요한 질문). 측정오차는 **이리듀서블 에러(irreducible error, 노이즈)**이기 때문에 학습으로 절대 줄일 수 없는 값. 줄이려는 건 측정오차가 아니라 "나의 예측값과 실제값의 차이"임.

## 6. 손실 함수 (Loss Function)

- 모델의 예측이 정답에서 얼마나 벗어났는지를 **하나의 숫자**로 나타내는 함수
- 학습이란 이 숫자가 **작아지는 방향**으로 조금씩 모델을 고쳐나가는 과정
- 문제 유형에 따라 사용하는 손실 함수가 다름

| 문제 유형 | 손실 함수 | 설명 |
|-----------|-----------|------|
| 회귀 | **평균제곱오차 (MSE)** | 정답과 예측의 차이를 제곱해서 평균낸 값. 많이 틀릴수록 제곱 때문에 손실이 커짐 |
| 분류 | **교차 엔트로피 (Cross Entropy)** | 정답 범주에 얼마나 높은 확률을 주었는지 측정. 정답을 확신할수록 손실이 0에 가까워짐 |

## 7. 회귀 평가지표 — MSE vs R²

MSE와 R² 모두 **모델의 정확도를 평가하기 위한 정량 지표**.

| 항목 | MSE | R² |
|------|-----|-----|
| 정의 | 예측값과 실제값 차이의 제곱 평균 | 평균 예측 대비 모델의 상대적 성능(라벨 분산 중 피처로 설명되는 비율) |
| 값 범위 | 0 ~ ∞ (무한대) | 0 ~ 1 |
| 단위 | 실제 데이터 단위² | 단위 없음 |
| 해석 | 절댓값 (구체적 오차 크기) | 상대적 비율 (성능 정도) |
| 좋은 값 | 0에 가까울수록 좋음 | 1에 가까울수록 좋음 |
| 장점 | 구체적 오차 크기를 알 수 있음 | 직관적 해석, 모델 간 비교가 쉬움 |
| 단점 | 직관적 해석이 어려움 | 구체적 오차 크기를 알 수 없음 |

- **MSE**: 각 데이터에서 정답과 예측의 평균 제곱 차이값. 틀린 정도를 제곱해서 더 큰 오류에 패널티 부여. 제곱 단위라 해석이 어려우면 루트를 씌운 **RMSE**도 사용
- **R²**: 평균만으로 예측하는 단순한 방법보다 모델이 실제값을 얼마나 더 잘 맞추는지 0~1 사이로 나타냄. 1에 가까울수록 설명력이 높음

**직관 비교 예시**
- MSE 관점: "평균적으로 천만 원 정도 실제값과 차이가 있다"
- R² 관점: "모델이 데이터 변동의 80%를 설명한다"

**언제 무엇을 쓸까**
- MSE: 구체적 오차 크기가 중요할 때, 실제 손실 비용을 계산할 때
- R²: 모델 성능을 직관적으로 평가할 때, 여러 모델을 비교할 때
- 필요에 따라 적절히 골라 쓰면 됨

## 8. 분류 평가지표 — Accuracy, Confusion Matrix, F1-score

분류 모델은 Label이 범주로 되어 있기 때문에 MSE나 R²를 사용하기 어렵다.

### 정확도 (Accuracy)

전체 예측 중에서 올바르게 맞춘 예측의 비율

```
Accuracy = (1/n) × Σ I(y_i = ŷ_i) = 올바르게 맞춘 개수 / 전체 예측 개수
```

- I: 지시(indicator) 함수. 조건이 참이면 1, 거짓이면 0을 반환
  - I(y_i = ŷ_i) = 1  → 실제값 = 예측값 (맞춤)
  - I(y_i ≠ ŷ_i) = 0  → 실제값 ≠ 예측값 (틀림)

> **참고**: 지시함수 개념은 꼭 기억할 것 — 시험에 나올 가능성이 높다고 언급됨

**정확도 99%면 무조건 좋은 모델일까?**

→ 아니다. **불균형 데이터**에서는 전부 음성(negative)이라고만 찍어도 정확도가 99%로 보일 수 있다.

### 혼동 행렬 (Confusion Matrix)

| 구분 | 설명 |
|------|------|
| **TP** (True Positive) | 실제 양성 → 예측도 양성 |
| **TN** (True Negative) | 실제 음성 → 예측도 음성 |
| **FP** (False Positive, 오탐) | 실제 음성 → 양성으로 예측 (예: 스팸 필터에서 정상 메일이 걸러지면 치명적 — 메일 누락) |
| **FN** (False Negative, 누락) | 실제 양성 → 음성으로 예측 (예: 병원 진단, 화재 감지 등에서 치명적) |

- **정밀도 (Precision)**: TP / (TP + FP)
- **재현율 (Recall)**: 진짜 양성 가운데 잡아낸 양성 예측의 비율. TP / (TP + FN)
- **F1-score**: 정밀도와 재현율의 **조화 평균**. 클수록 좋음

## 9. 크로스 엔트로피 (Cross Entropy)

**정확도만으로 학습이 가능할까?** → 어렵다.

- 정확도·혼동행렬은 **학습이 끝난 결과를 평가**하는 지표. 맞음/틀림만 세기 때문에 예측 확률이 좋아져도 값이 그대로일 수 있다.
- 정답을 얼마나 확신했는지까지 반영하는 손실이 필요 → **크로스 엔트로피**

**정의**: 정답 범주에 준 확률이 높을수록 손실이 작아짐. 확률이 낮으면 손실이 급격히 커짐.

```
손실 = −log(정답 범주에 준 확률)
```

**예측 확률에 따른 교차 엔트로피 손실 예시** (실제 정답: 스팸)

| 스팸일 확률 예측 | 손실 −log(p) |
|------------------|----------------|
| 0.9 | 0.11 (작음) |
| 0.6 | 0.51 |
| 0.1 | 2.30 (큼) |

분류 문제의 대표 손실 함수.

## 10. 일반화, 오버피팅, 언더피팅

### 학습의 목적

모델이 훈련 데이터에서만 잘하는 게 아니라, **새로운 데이터에서 예측을 잘하는 것**이 궁극적 목표.

- 모델 성능 평가는 **모델이 처음 보는 데이터**로 확인해야 한다.
- 훈련 데이터에서 아무리 성능이 좋아도, 새로운 데이터에서 성능이 떨어지면 실전에서 사용 불가.
- **일반화 오류 최소화**가 지향점 — 새로운 데이터에서 틀리는 것을 최대한 줄여야 한다.

### 훈련 오류 vs 테스트 오류

| 구분 | 설명 |
|------|------|
| **훈련 오류** | 모델을 학습시킨 것과 같은 데이터에 다시 적용해 계산한 오류 |
| **테스트 오류** | 학습에 쓰지 않은 새 관측치에 모델을 적용했을 때의 평균 예측 오류 |

- 훈련 오류는 테스트 오류와 다르며, **훈련 오류는 테스트 오류를 과소평가하는 경우가 많다.**
- 훈련 오류는 계속 낮아지지만, 테스트 오류는 **U자형**을 그린다 → 테스트 오류가 최소가 되는 적절한 모델을 찾는 것이 목표.
- 비유: 너무 많이 답을 외우지도, 너무 대충 공부하지도 않은 딱 적당한 지점을 찾기.

### 오버피팅 (Overfitting)

- 훈련 데이터의 **우연한 패턴(잡음)까지 외워버려서**, 훈련에서는 잘 맞지만 테스트에서는 성능이 나빠지는 현상
- 현상: 훈련 오류는 급격히 낮은데 테스트 오류는 높고 요동침

**오버피팅이 왜 안 좋은가**
- **표본 의존·불안정**: 훈련 데이터는 모집단의 일부이며 우연한 잡음이 섞여 있음. 이 잡음까지 과하게 맞추면 샘플 몇 개만 바뀌어도 예측이 크게 흔들림
- **일반화 실패**: 보지 못한 데이터에서 오류가 커지고, 모집단 성능과의 격차가 벌어짐

### 오버피팅에 대한 오해

**오버피팅 ≠ 분포 변화(distribution shift)로 인한 에러 증가**

- **분포 변화로 인한 오류**: 훈련 데이터 분포와 테스트 데이터 분포가 다름으로써(환경·계절·센서 변경 등) 성능이 떨어지는 현상. 예: 훈련 데이터는 단순한 일러스트/그림체 이미지인데 테스트 데이터는 실제 사진인 경우
- 분포 변화로 인한 에러 증가는 **모델이 과적합하지 않아도 발생 가능**

> `[개인 메모 · 시험범위 아님]` 분포 변화로 인한 에러 → 데이터 누수(data leakage)와 관련 있는 개념인지??? (추가 확인 필요)

### 언더피팅 (Underfitting)

- 모델이 너무 단순하거나 학습이 완료되지 않아 **중요한 패턴을 놓치는 상태** (오류가 큼)
- 해결 실마리: 더 많은 데이터 확보, 테스트 데이터를 활용한 모델 선정, 교차 검증 등

## 11. 테스트 오류 추정 방법 (검증셋 vs K-겹 교차검증)

### 테스트 오류 계산의 현실적 문제

- **이상적인 방법**: 충분히 큰 별도의 테스트셋을 사용하는 것. 하지만 현실에서는 테스트만을 위한 데이터를 따로 마련하기엔 데이터 자체가 부족한 경우가 많음
- **대안: 재표본화(resampling)를 통한 테스트 오류 추정** — 데이터를 나누어 여러 번 훈련/평가를 반복해 테스트 오류를 추정 (비유: 기존 문제집 문제를 활용해 모의고사를 보는 것)
- 대표 방법: **검증셋(validation set) 접근**, **K-겹 교차검증(K-fold Cross-Validation)**
  - 장점: 별도의 테스트 데이터 없이도 데이터를 더 효율적으로 사용하여 일반화 오차를 추정할 수 있음

### 검증셋(홀드아웃) 접근

- 가용한 샘플들을 무작위로 **훈련셋(train set)**과 **검증셋(validation set)**으로 분할
- 훈련셋으로 모델을 적합(fit)하고, 검증셋으로 예측해 **검증 오류**를 계산
- 검증 오류 지표
  - 정량적(회귀) 반응: MSE
  - 범주형(분류) 반응: 오분류율 또는 F1-score
- 절차: 데이터 순서를 무작위로 셔플링 → 두 부분으로 분할 → 훈련셋에서 학습, 검증셋에서 성능 평가

**예시: 자동차 데이터**
- 목표: 선형(1차) 모델부터 고차항(다항식) 모델까지 비교
- 392개 데이터를 무작위로 196개 훈련셋 / 196개 검증셋으로 분할 (일반적으로 정확히 반으로 나눌 필요는 없음)
- 단 한 번 분할했을 때의 MSE 곡선과, 여러 번(셔플 후) 다른 분할로 얻은 MSE 곡선들을 비교해보면 — **분할에 따라 곡선의 모양이 상당히 달라짐**

### 검증셋 접근의 한계

- 어떤 표본이 훈련/검증에 들어가느냐에 따라 검증 기반 테스트 오류 추정치가 **매우 가변적(variable)**
- 검증셋 접근은 훈련셋(전체의 일부)만으로 모델을 적합하므로, **전체 데이터로 학습했을 때보다 성능이 낮게 추정**될 수 있음
  - 이유: 학습 데이터의 일부만 사용하기 때문에, 전체 데이터로 학습한 경우보다 예측 성능이 낮게 나올 수밖에 없음

## 12. K-겹 교차검증 (K-fold Cross-Validation)

**테스트 오류 추정의 표준적 접근.** 비유: 문제집을 5등분해서 서로 다른 모의고사를 5번 보는 것.

- 추정치는 **모델 선택**과 **최종 모델의 테스트 오류 규모 파악**에 활용
- 데이터 전체를 크기가 동일한 K개의 폴드(fold)로 무작위 분할
  → 폴드 k ∈ {1, 2, ..., K}를 검증셋으로, 나머지 K−1개 폴드를 훈련셋으로 사용
- k = 1, ..., K에 대해 이 과정을 반복한 후, **평균 오류로 테스트 오류를 추정**

**절차 정리**
1. 데이터를 먼저 셔플링
2. 총 n개의 데이터를 **겹치지 않는** K개 그룹으로 분할
3. 각 그룹이 번갈아 검증셋이 되고, 나머지는 훈련셋이 됨
4. K개의 MSE를 평균 내어 테스트 오류를 추정

**보통 K는 5 또는 10 정도로 설정.** (5-fold, 10-fold가 관행적으로 많이 쓰임)

> 검증셋 접근과 비교하면, 서로 다른 K번의 분할에 대한 오류 곡선들의 **경향과 최적 차수(degree)가 비슷하게** 나오는 것을 확인할 수 있음 — 즉 K-겹 교차검증이 단일 검증셋보다 더 안정적인 추정치를 준다.

> `[개인 메모 · 시험범위 아님]` 새로운 모델을 생성하고, 가중치를 초기화한 뒤 처음부터 학습합니다. 각 fold의 목적은 성능을 평가하는 것이므로, 모델들의 가중치를 평균내거나 중간값을 구하지도 않습니다. K-fold는 어떤 모델이 가장 좋은지 고르는 과정이고, 선택이 끝나면 전체 데이터를 이용해 새로 최종 모델을 학습하는 것이 일반적입니다.

### K-겹 교차검증 오류 계산

- 폴드 집합 C₁, ..., C_K, 각 폴드 크기 nₖ

```
CV(K) = Σ (nₖ/n) × MSEₖ      (k = 1 ~ K)
```

- 여기서, MSEₖ = (1/nₖ) × Σ (yᵢ − ŷᵢ)²  (i ∈ Cₖ)
  - K번째 폴드를 검증셋으로 두고, 나머지로 적합한 예측 ŷᵢ 사용
  - **MSE (평균제곱오차)**: 예측이 얼마나 틀렸는지를 숫자로 표현한 값 (오차를 제곱해 평균)

- **K = n**이면 **Leave-One-Out 교차검증 (LOOCV)**
  - 100개의 문제(n)로 100개의 서로 다른 모의고사(K)를 만드는 것
  - 참고만 할 것 — 교수님 언급: **실제로는 잘 사용하지 않음**

> LOOCV는 데이터 하나만 검증셋으로 남기고 나머지 n−1개로 학습하는 것을 n번 반복하는 방식으로, 계산 비용이 매우 크기 때문에 일반적으로 K=5 또는 K=10을 사용하는 K-겹 교차검증이 실무에서 더 선호된다.

> `[개인 메모 · 시험범위 아님]` 질문: k폴드를 하는 이유가 가설공간이 적합한지 보려고 하는건가??
>
> **답변**: 어느 정도는 맞는 방향이다. K-겹 교차검증은 여러 후보 모델(예: 다항식 차수가 다른 모델들 — 서로 다른 가설공간 혹은 같은 가설공간 내 다른 후보 함수)을 비교해서 **어떤 모델이 가장 일반화를 잘 하는지 고르는 모델 선택(model selection)**에 쓰인다. 다만 핵심 목적은 "가설공간 자체가 적합한가"를 검증하는 것이라기보다는, **제한된 데이터로 테스트(일반화) 오류를 안정적으로 추정**하는 데 있다. 단일 검증셋 분할은 어떤 샘플이 훈련/검증에 들어가느냐에 따라 추정치가 크게 흔들리는데(가변적), K번 서로 다르게 분할해서 평균을 내면 이 변동성(분산)이 줄어들어 더 신뢰할 수 있는 오류 추정치를 얻을 수 있다. 이렇게 얻은 안정적인 추정치를 이용해 결과적으로 "어떤 차수/어떤 모델(가설공간 내 후보)이 가장 적합한지"를 판단하게 되는 것이다.

**K-겹 교차검증은 테스트 성능을 추정하는 좋은 대안이다.**

## 13. 비지도 학습 (Unsupervised Learning) — 개요

- **정의**: 레이블(정답) 없이 데이터의 **구조·패턴·집단**을 찾아내는 학습
- **대표 과제**: 클러스터링(clustering), 차원축소(dimensionality reduction), 밀도 추정(density estimation), 이상치 탐지(anomaly detection)
- **출력**: 정답 예측이 아니라 **구조 요약·표현**

**지도학습 vs 비지도학습**

| 구분 | 학습 방식 |
|------|-----------|
| 지도학습 | 입력 + 라벨로 예측 모델 학습 |
| 비지도학습 | 입력만으로 구조를 학습 |

**핵심 질문**
- 무엇을 "비슷함/다름"으로 볼 것인가 (거리·유사도 선택)
- 전처리(스케일링, 표준화 등)를 어떻게 할 것인가

### 클러스터링 (Clustering)

- 서로 비슷한 데이터끼리 묶어 **동질적인 그룹**을 만드는 것
- **군집화**: 데이터 안에서 하위 집단(subgroup)을 찾는 기법들을 통칭하는 말

## 14. K-평균 클러스터링 (K-means Clustering)

### 클러스터링의 기본 목표

- **집단 내부는 서로 유사하게, 집단 간은 서로 상이하게** 데이터를 분할
- "유사/상이"의 기준은 **문제 도메인에 따라 달라짐**
- 특성에 따라 클러스터가 잘 안 보이거나, 알고리즘마다 결과가 달라질 수 있음
- 예: 시장 세분화(market segmentation) 자체가 클러스터링의 대표적 활용 사례

### 두 가지 대표 클러스터링 기법

| 기법 | 특징 |
|------|------|
| **K-평균 (K-means)** | K를 미리 정해두고 분할 |
| **계층적 군집 (Hierarchical Clustering)** | K를 사전에 고정하지 않음 |

### K-means의 표기 (군집 집합)

- 관측치 인덱스 집합을 C₁, ..., C_K 라 하면:
  - C₁ ∪ ⋯ ∪ C_K = {1, ..., n} (각 관측치는 적어도 하나의 군집에 속함)
  - 모든 다른 클러스터 k ≠ k'에 대해, Cₖ ∩ Cₖ' = ∅ → 하나의 데이터가 여러 그룹에 동시에 속할 수 없음
  - i번째 관측치가 k번째 군집이면 i ∈ Cₖ (비중첩 분할)
- 정리: 모든 데이터를 **겹치지 않게**(K개 군집이 서로 겹치지 않음), **빠짐없이**(K개 군집 중 하나에는 반드시 포함), **정확히 하나의 군집에만** 나눔

### K-means 결과 해석

- K=2, 3, 4 등으로 K-means를 실행한 결과를 점마다 색상으로 표시해 할당된 클러스터를 확인
- **특정 색상 자체는 의미가 없음** — 점들이 다른 색이라는 것은 서로 다른 클러스터에 속해 있다는 의미일 뿐
- **정답(라벨)이 있는가? 없다.** 비지도학습이므로 정해진 정답 없이 데이터의 구조에 따라 그냥 나누는 것

### 좋은 클러스터란?

- **클러스터 내부 변동(within-cluster variation)이 작은 분할**
- 클러스터 내 거리 차이의 합이 **최소가 되도록** 데이터를 나누는 것
- 그룹 안에서 데이터들이 얼마나 모여 있는지를 기준으로 K개 그룹을 만드는 알고리즘

### K-means 알고리즘 절차

1. **초기화(Initial)**: 관측치들에 무작위로 1~K 클러스터를 임시 부여
2. **반복** (할당이 더 이상 바뀌지 않을 때까지)
   - 각 클러스터의 중심 계산 (특성 평균 벡터)
   - 각 관측치를 가장 가까운 중심의 클러스터로 재할당 (거리 측정: 예. 유클리드 거리)

### K-means 알고리즘의 특성

- 중심점과의 평균 거리가 매 반복마다 계속 줄어들기 때문에, 반복할수록 결과가 더 좋아짐
- 하지만 **항상 최적해를 찾는 것은 아님** — 초기값에 따라 **지역 최솟값(local minimum)**으로 수렴할 수 있음 (로컬 미니멈 문제)
- 서로 다른 초기 할당(레이블)에서 시작하면 최종 분할과 목표값(내부 변동)이 달라질 수 있음
- **초기화의 중요성**: 초기값이 랜덤이기 때문에, 여러 번 시도해보는 것이 권장됨

### K-means의 치명적 단점

- **K를 미리 지정해야 함** — K-means의 대표적인 한계
- 반면 **계층적 군집**은 K를 미리 고정하지 않고, 전체 구조를 **덴드로그램(dendrogram)**으로 제공
  - (이번 강의에서는 **상향식(잎 → 몸통으로 병합)** 방식을 다룸)
  - 덴드로그램에서 **수평선 높이를 기준으로 가위질**하여 K개 군집을 얻음
  - 높이가 정보를 담고 있어 사후 판단이 용이함

## 15. 계층적 군집 (Hierarchical Clustering) — 상향식

### 알고리즘 절차

1. n개의 관측치에 대해 **쌍별 비유사도(pairwise dissimilarity)** 계산
2. 각 관측치를 하나의 클러스터로 시작
3. 클러스터 간 쌍별 비유사도를 모두 계산해 **가장 유사한 두 클러스터를 병합**
4. 병합 후 남은 클러스터들 사이의 새 비유사도를 다시 계산
5. 위 과정을 반복

- **상향식(bottom-up)**은 큰 그룹을 나누는 것이 아니라, 작은 클러스터들을 점점 **합쳐나가는 과정**
- 데이터들이 유클리디안 거리(Euclidean distance) 등에 따라 가장 가까운 순으로 점차 큰 클러스터로 합쳐지는 과정
- 매 단계에서 클러스터들끼리의 병합이 이루어지며, **1개의 단일 클러스터가 될 때까지** 진행

### 계산 비용

- 매 단계마다 **모든 클러스터 쌍 간의 거리**를 계산해야 함
- 데이터 수가 많은 경우, K-means에 비해 **계산량이 많음**

### 링크(Linkage) 유형

| 링크 유형 | 설명 |
|-----------|------|
| **최소 거리 링크** | 두 클러스터 간 가장 가까운 점들의 거리를 기준으로 함 |
| **최대 거리 링크** | 두 클러스터 간 가장 먼 점들의 거리를 기준으로 함 |
| **평균 거리 링크** | 두 클러스터 간 모든 점 쌍의 평균 거리를 기준으로 함 |

- 문제 상황에 맞게 **적절한 링크를 선택**해야 함
- **링크 유형별로 덴드로그램이 달라질 수 있으니, 여러 링크를 시도해보는 것이 좋음**

### 스케일링 필요성

- **스케일링(scaling)이 필요한가?** → 필요함. 변수 단위 차이가 거리 계산에 미치는 영향이 크기 때문
