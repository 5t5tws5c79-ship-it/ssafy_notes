# 06. 반복문 & 조건문

`for` / `while` 과 `if` / `elif` / `else` 만으로 푸는 기본기 연습.
**dict 도, `defaultdict` 도, 내장 함수 `max()` / `sum()` 도 쓰지 않는다.**
리스트를 한 번 훑으면서 세고, 거르고, 비교하는 것에만 집중한다.

## 반드시 챙길 함정 4가지

```python
# 1. 조건 순서 — 넓은 조건을 위에 두면 아래는 영원히 도달하지 못한다
if score >= 60: return 'D'      # 95점도 여기서 걸려버림
elif score >= 90: return 'A'    # 절대 실행 안 됨

# 2. 최댓값 시작값 — 0으로 시작하면 전부 음수일 때 리스트에 없는 0이 답이 된다
biggest = numbers[0]            # 첫 값으로 시작해야 안전

# 3. 이상/이하 vs 초과/미만 — 등호 하나로 경계값이 사라진다
if low <= n <= high:            # 5, 15 포함
if low <  n <  high:            # 5, 15 빠짐

# 4. 2차원 리스트 생성 — 곱셈으로 만들면 모든 행이 같은 리스트가 된다
bad  = [[0] * 3] * 3            # 한 칸 바꾸면 세 행이 같이 바뀜
good = [[0] * 3 for _ in range(3)]
```
